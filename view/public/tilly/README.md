# 틸리 그림 넣는 곳

`lib/Tilly.jsx` 가 **이 폴더만** 본다. 파일 이름이 곧 표정 이름이다.

| 파일 | 표정 (캐릭터 시트) | 쓰이는 자리 |
|---|---|---|
| `hello.png` | 안녕하세요! | 스플래시 · 소개 · 홈 인사 |
| `ask.png` | 궁금한 게 있으세요? | 챗봇 첫 화면 · 떠 있는 「상담」 단추 |
| `checking.png` | 확인해볼게요! | 챗봇이 답 찾는 중 |
| `wait.png` | 조금만 기다려주세요! | 불러오는 중 |
| `done.png` | 도움이 되었길 바라요! | 답을 마친 뒤 |
| `bye.png` | 또 만나요! | 로그아웃 |

## 규격

* **투명 PNG**. WebP 를 쓰려면 `lib/Tilly.jsx` 의 `EXT` 한 줄만 바꾼다
* **찍힐 크기의 3배로.** 폰마다 화면 배율이 달라 등배로 주면 뭉갠다

  | 자리 | 찍히는 높이 | 권장 파일 높이 |
  |---|---|---|
  | 떠 있는 단추 | 34px | 102px 이상 |
  | 홈 인사 · 챗봇 | 64px | 192px 이상 |
  | 스플래시 · 소개 | 132px | 396px 이상 |

* 여섯 장을 한꺼번에 안 넣어도 된다. **없는 것은 그냥 안 그린다** —
  넣은 것부터 나타난다

## 안 쓰는 곳

⚠ **검사 결과 · 안내문 화면에는 넣지 않는다.** 「도움이 되었길 바라요!」
같은 표정이 악성 소견 옆에 뜨면 위로가 아니라 실례가 된다.
