# 규칙 없는 이름 — 이미 있던 것
# ════════════════════════════════════════════════════════════════
#
# scripts/check-names.mjs 가 읽는다. 여기 적힌 이름은 **실패시키지 않는다.**
# 목적은 «새로 생기는 이름»을 잡는 것뿐이다 — 이번에 달력이 두 번 깨진
# 원인이 둘 다 이름이었다(.cal 충돌 · .cal-dot 하나만 안 갈림).
#
# 두 종류가 들어온다.
#   이름      CSS 에 규칙이 없는 클래스
#   --이름    정의가 없는 토큰 (var(--…) 로 쓰는데 값이 어디에도 없다)
#
# ⚠ **여기 있는 것을 고치려 들지 마라.** 규칙 없는 «클래스»가 곧 버그는
#   아니다 — querySelector 손잡이일 수도, 검사용 선택자일 수도 있다.
#   lib/dicom/** 과 dept/breast/components/** 는 손대지 않기로 한 자리다.
#
# ⚠ **정의 없는 «토큰»은 다르다 — 그건 거의 다 버그다.** 정의가 없으면
#   브라우저가 그 선언을 통째로 버리는데 오류는 안 난다. 그래서 여기에
#   토큰을 적어 두는 일은 없어야 한다 — 2026-09-21 에 드러난 셋은
#   그날 바로 고쳤다. 새로 생기면 그 자리에서 실패시킨다.
#
# ⚠ 이 목록에 있는데 더는 안 걸리는 줄이 생기면 검사가 경고를 낸다.
#   그때 그 줄을 빼라. 안 그러면 목록이 썩어서 아무도 못 믿는다.
#
# 적는 법 — 이름 한 칸 띄고 어느 파일인지. # 로 시작하면 주석이다.
#
