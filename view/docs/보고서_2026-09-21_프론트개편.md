## 3. 2묶음 — 과 홈 (완료)

`lib/Home.jsx` · `dept/home.js` · `lib/notes.js` 신규, 과별 `home` 블록 추가.
**다섯 과가 한 틀**이다 — 화면은 `Home.jsx` 하나고 칸 내용만 과가 준다.

```
과 이름  2026-09-21 (월) ················ [주 동작]
최근 본 환자  [칩][칩] ······· 내 계정으로 연 환자만 보입니다
┌ 1.5fr ───────────┬ 1fr ──────┬ 330px ─┐

│ 주 큐             │           ├────────┤
├──────────────────┤           │ 할 일   │
│ 확인이 필요한 것   │ 인계 사항  │        │
└──────────────────┴───────────┴────────┘
```

- **인계 사항은 가운데 칸 아래**, 할 일은 오른쪽 달력 아래
- 할 일·인계는 `lib/notes.js` 뒤에 숨김 — 지금은 localStorage, 서버 표가 생기면 `read`/`write` 두 함수만 교체
- 최근 본 환자는 **메모리에만** — 공용 PC라 브라우저에 환자 이름·번호를 남기지 않음
- **경과 시간(평균 대기 23분 · 1h12m)은 한 군데도 쓰지 않음** — 서버가 주지 않는 값
- 칸은 카드로 띄우지 않고 1px 선으로 가름

**서버가 값을 안 줘서 비워 둔 칸** (칸은 세우고 안만 비움)

| 칸 | 비는 과 | 왜 |
|---|---|---|
| 오늘 한 일 | 원무 · 간호 · 유방외과 | 오늘 몇 건 했는지 뽑는 경로 없음 |
| 달력 점 | 영상 · 병리 · 유방외과 | 근무표(판독 당번·수술) 표 자체가 없음 |
| 확인이 필요한 것 | 일부 줄 | 거르는 조건이나 표가 없음 |
| 선생님별 칸 | 유방외과 | `?primary_staff=` 가 `"me"` 만 받음 |

## 4. 잡은 버그 — 전부 화면을 띄워야 보이는 것들

**`npm run build`와 `npm run lint`를 전부 통과한 것들이다.**

| # | 증상 | 원인 |
|---|---|---|
| 1 | 다섯 과 홈 전부 흰 화면 | `ScreenChips`가 홈 설정 객체를 `menuScreens`에 넘김 — 두 객체가 `key`·`name`만 겹치고 `screens`가 없음 |
| 2 | 간호 홈 칸 0개 | `load`가 `Promise.all` — 곁가지 호출 하나가 404 나면 홈 전체가 오류 화면 |
| 3 | 목업 404 | `mock/hospital.json` 열쇠가 `followups?…`인데 호출은 `followups/?…` (DRF 라우터는 슬래시 쪽) |
| 4 | 달력이 101px 잘림 | `.cal` 이름 충돌 — 예약 캘린더 화면 규칙(1429행)이 덮어씀. **`--cal-cell-h` 토큰도 중복 정의되어 예약 캘린더를 조용히 망가뜨리고 있었음** |
| 5 | 오늘 날짜 숫자가 검은 칸 위로 3.8px 삐져나감 | 점 클래스가 `cal-dot`으로 남아 있었고, 수식어 `none`이 전역 규칙(`padding:10px 0`)과 충돌해 4px 점이 20px가 됨 |
| 6 | 상단 머리 줄 8.3px 어긋남 | 제목 `line-height`와 버튼 높이가 따로 놂 |

**4·5는 둘 다 CSS 이름 충돌이다.** 브라우저 검사로는 증상만 보이고 원인이 안 보인다.

### 측정값 (1920×855, 확대 100%)

```
달력 칸       328 / 429 → 101px 넘침        → 0
달력 머리     143 / 165 →  22px 넘침        → 0
오늘 숫자     셀 위로 3.8px 밖              → 셀 안 (위 4.2 / 아래 10.8)
점            20px                          → 4px
머리 줄 중심  8.3px 어긋남                  → 0
부모를 벗어난 요소 · 가로 스크롤 · 글자 잘림 · 겹침 → 전부 0
```

## 7. 서버에 요청할 것

**순서는 화면 → DB → 엔드포인트다. 지금 만들지 않는다.**

| # | 무엇 | 크기 |
|---|---|---|
| 1 | `GET /home?dept=` — 홈 요약 한 방 | 뷰 1개 + urls 1줄, 마이그레이션 없음 |
| 2 | `staff_note` 표 — 할 일·인계·메모 | 마이그레이션 1개 |

| 5 | `POST /specimens` — 검체 생성 | 보낼 칸 목록 문서에 적음 |
| 6 | 예약 변경·취소 경로 | 상태만 바꾸고 기록은 남김 |
| 7 | **나이 계산** — 갈림길, 응답 먼저 확인 | 아래 참고 |
| 8 | 신환 등록에 `sex` 필수 추가 | 지금은 `name·birth_date·phone` 셋뿐 |
| 9 | timeline 이벤트에 `kind`·`ref_id` | 이미 실려 오면 할 일 없음 |

**7번이 급하다.** 나이를 세는 코드가 세 곳에 따로 있고(`api.js` · `PatientBar.jsx` · `reception/Patients.jsx`)
**셋 다 `올해 − birth_year`라 만 나이가 아니다.** 생일 안 지난 사람은 한 살 많게 나온다.

> ⚠ 검색·목록 응답에 `birth_date`가 오는지 **주석 셋이 서로 다르다.**
> `GET /patients/?q=…` 응답을 한 번 까 보고 정한다 —
> 오면 프론트가 만 나이로 세고(`normalizePatient` 한 곳에만),
> 안 오면 `PatientSerializer`에 `age` 한 줄을 더한다(`/exam-orders`는 이미 준다).
> 정해지면 세 곳을 지우고 **그 뒤에** `patient.birth_year`를 버린다.

## 8. 오늘 내린 결정

| 사안 | 결정 | 근거 |
|---|---|---|
| 원무과 + 간호과 | **「접수·간호」 한 과로 합친다** | 접수→내원→호출→문진→배정이 한 줄. `perm.js`가 이미 과가 아니라 화면 단위라 권한 키를 한 줄도 안 바꿔도 됨 |
| `patient.birth_year` | **버린다** (단 서버가 `age`를 준 뒤에) | `birth_date` 하나로 충분. 이름 없이 나이만 쓰는 경로는 뷰로 |
| `patient.sex` | **옮기지 않는다** | 유방암에서 임상 변수이고, 법적으로도 민감정보가 아님(개인정보보호법 시행령 제18조에 성별 없음) |
| 예약 담당의 | **환자의 `primary_staff`로 묶는다** | `POST /exam-orders/schedule`이 `patient_id`·`scheduled_at` 둘만 받음. 서버에 칸을 새로 만들지 않음 |
| 「부도」 표기 | **쓰지 않는다** → 「안 오신 적 n번」 | 창구에서 내원을 안 찍었을 수도 있어 단정 불가. 횟수·날짜만 보이고 판단은 사람이 |
| 최근 본 환자 | **브라우저에 저장하지 않는다** | 판독실 PC는 공용, `localStorage`는 로그아웃해도 남음 |
| 캔버스 목업 | **HTML 원본을 `docs/mockup/`에 넣어 전달** | 그림을 글로 옮겨 적는 방식이 매번 어긋남 |

## 10. 배운 것

- **`build`·`lint` 통과는 「돈다」는 뜻이 아니다.** 오늘 잡은 버그 여섯이 전부 그 둘을 통과했다.
- **CSS 이름 충돌이 조용히 남의 화면을 망가뜨린다.** `--cal-cell-h` 중복 정의로 예약 캘린더가 깨져 있었는데 아무도 몰랐다.
- **그림을 글로 옮겨 적으면 매번 어긋난다.** 목업 HTML 원본을 주고 나서야 배치가 맞았다.
- **측정값 없이 「어긋납니다」라고 하면 안 고쳐진다.** 「8.3px」이라고 적어야 고쳐진다.
