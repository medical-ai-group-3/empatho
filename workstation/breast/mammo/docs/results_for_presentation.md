# 발표용 확정 수치 — 맘모그래피 파트

갱신 2026-09-08 · 박검모 (모델 조정 2026-09-07 종료 · 정상 유방·서빙 실측 추가)

**에폭 8 이 최종본이다.** 에폭 12 는 실제로 돌려 보고 기각했다 — 학습 손실은 29.6→18.2 로 계속 내려가는데 검증 손실이 7.15→9.33 으로 올랐다. 전형적인 과적합이다.

**모델 조정은 끝났다.** 순위를 올리려고 12가지를 시도해 2가지가 성공했고(조직 타일 필터 · 유방 깊이 가중), 서술어 쪽은 천장을 재어 모델이 이미 0.4~4.5%p 안에 붙어 있음을 확인했다. 자세한 것은 10절.

**09-08 에 마지막 측정을 하나 더 했다.** 그때까지 한 번도 안 보던 쪽 — 병변이 없는 유방(7-2절)과, 실제 서빙 경로에서 잰 추론 시간(11절)이다. 이후 성능 수치는 바뀌지 않는다.

이 문서에는 **측정으로 확인된 값만** 적는다. 진행 중이거나 미확인인 것은 그렇게 표시한다.
발표와 질의응답에서 이 문서 하나만 보면 되도록 정리했다.

## 한 줄 요약

> 사진 한 장을 넣으면 조직검사가 필요한 병변의 **70.2%** 를 스스로 찾아 판단한다.
> 병변 위치를 알려주면 **90.0%** 다. 그 차이의 **92% 가 검출 단계**에서 생긴다.
> 검출에서 미세석회가 18.6% 에 그쳤는데, 원인이 모델이 아니라 전처리에서
> 신호의 84% 를 잃은 것임을 특정했다. 원본 해상도 타일로 다시 만들어
> **미세석회 검출을 57.9% 로 올렸다(3.1배).**

**이전 판의 정정** — 여기 적혀 있던 `민감도 98.2%` 는 **미세석회만의 값**이었다.
종괴는 같은 조건에서 82.7% 이고, 둘을 합치면 90.0% 다. 서술어 시스템 전체의
민감도로 98.2% 를 말하면 종괴에서 다섯에 하나를 놓치는 것이 가려진다.

## 1. 시스템 구성

모델이 두 개다. 하나로 뭉쳐 말하면 어느 쪽도 정확하지 않다.

| | 하는 일 | 입력 | 출력 | 상태 |
|---|---|---|---|---|
| **검출기** | 병변 위치 찾기 | 유방 영상 전체 | 박스 + 점수 | 개선 중 |
| **서술어 시스템** | 성질 기술 → 등급 → 판단 | 병변 조각 | 서술어 · BI-RADS · 조직검사 여부 | 완성 |

```
맘모그램 → 검출기 → 박스 → 잘라내기 → 서술어 시스템 → 조직검사 여부
```

두 시스템을 **2026-08-30 에 이었다.** 검출기가 낸 박스를 잘라 서술어에 넣고
조직검사 판단까지 한 사슬로 잰다(6-2절). 그래서 이 문서에는 두 조건의 수치가
같이 나온다 — **① 위치를 알려줬을 때**와 **② 스스로 찾았을 때**. 발표에서는
반드시 둘을 나란히 말한다.

### 사용 모델

```
Sam3Image  840.5M
  시각 백본     ViTDet 32블록 · 창 어텐션 + 전역 어텐션 · RoPE
  텍스트 인코더  CLIP 계열 24층
  검출 디코더    인코더 6층 + 디코더 9층 · 객체 질의 200개 · DETR 계열
  짝짓기        헝가리안 매칭 (BinaryHungarianMatcherV2)
  입력          1008×1008 · 패치 14 · 격자 72²
가중치  MedSAM3 = SAM 3 기반 + 의료 LoRA 병합본
```

검출기를 따로 고른 것이 아니라 SAM 3에 원래 있는 것을 쓴다. 텍스트 프롬프트로
조건을 준다 — `"mass"` 와 `"calcification"` 으로 두 번 돌린다.

## 2. 서술어 시스템 — 확정

**조건: 병변 위치가 주어진 상태 (데이터셋 정답 ROI 사용)**

| 지표 | 미세석회 (n=313) | 종괴 (n=345) |
|---|---|---|
| 조직검사 판단 정확도 | **85.3%** | **73.3%** |
| 민감도 | **98.2%** | **82.8%** |
| 특이도 | 55.8% | 50.5% |
| PPV | 83.6% | 80.2% |
| NPV | 93.0% | 54.8% |
| '전부 조직검사' 기준선 | 69.6% | 70.7% |

**종류를 나눠서 말해야 한다.** 두 종류를 뭉쳐 하나의 수치로 말하면 종괴가
가려진다. 합친 민감도는 **90.0%** (놓친 병변 46/462) 다.

### 종괴 정확도는 기준선을 거의 못 넘는다 — 먼저 말해야 한다

종괴 정확도 73.3% 는 '전부 조직검사' 로 찍었을 때의 70.7% 를 **2.6%p** 밖에
안 넘는다. 이 조건에서 정확도는 자랑할 수치가 아니다.

다만 정확도가 잘못된 지표다. 특이도가 50.5% 이므로 전부 조직검사로 찍는 것과
다르게 행동한다 — 그쪽은 특이도가 0% 다. 균형 정확도로 보면

```
종괴   (82.8 + 50.5) / 2 = 66.7%      전부 조직검사 = 50.0%
석회   (98.2 + 55.8) / 2 = 77.0%      전부 조직검사 = 50.0%
```

**질문이 오면 이렇게 답한다** — "정확도만 보면 종괴는 기준선 대비 2.6%p 입니다.
다만 이 데이터는 조직검사 확정 사례만 모은 집합이라 양성이 70% 이고, 그런
불균형에서 정확도는 좋은 지표가 아닙니다. 특이도가 50.5% 라 실제로 층화하고
있고, 균형 정확도로는 66.7% 대 50% 입니다."

### 규칙표 자체의 상한이 종류마다 다르다

정답 서술어를 넣었을 때(사람이 완벽히 기술했을 때) 규칙표가 내는 값이다.

| | 규칙표 상한 | 서술어 모델 | 낙폭 |
|---|---|---|---|
| 미세석회 민감도 | 100.0% | 98.2% | -1.8%p |
| 종괴 민감도 | 85.2% | 82.8% | -2.4%p |
| 미세석회 정확도 | 90.3% | 85.3% | -5.0%p |
| 종괴 정확도 | 78.8% | 73.3% | -5.5%p |

**종괴 민감도가 낮은 주된 이유는 모델이 아니라 규칙표다.** 서술어를 완벽히
알려줘도 85.2% 가 상한이고, 모델은 거기서 2.4%p 만 더 잃는다. BI-RADS 어휘집이
종괴를 기술하는 방식(모양·경계)만으로는 악성 여부가 그만큼밖에 안 갈린다.

우리가 고칠 수 있는 것과 없는 것이 여기서 갈린다. 서술어 모델을 아무리 잘
만들어도 종괴는 85.2% 를 못 넘는다.

### 등급 정확도가 낮아 보이는 이유

같은 서술어 조합이 실제 데이터에서 여러 등급으로 나뉜다. `다형성 + 군집성`
453건의 정답 등급이 4·5·3·2로 흩어져 있다. 규칙표는 조합 하나에 등급 하나를
배정할 수밖에 없으므로 그만큼은 어떤 규칙표로도 못 맞힌다.

측정으로 확인한 상한 (테스트 분할 654행 기준).

| | 등급 정확 일치 | 조직검사 판단 |
|---|---|---|
| 정답 서술어 + 현재 규칙표 | 70.6% | 84.3% |
| 서술어로 도달 가능한 최대 | 71.9% | 84.4% |

**규칙표를 고쳐서 얻을 수 있는 몫이 조직검사 판단에서 0.1%p다. 튜닝은 끝났다.**
그 위로 올라가려면 서술어에 없는 정보 — 병변 크기, 이전 촬영과의 변화, 환자
이력 — 가 필요하다.

### 서술어는 위험을 실제로 층화한다

조합별로 조직검사에서 실제 악성으로 나온 비율이 임상 서열대로 올라간다.

| 서술어 조합 | 건수 | 실측 악성률 |
|---|---|---|
| 가려짐 + 난원형 | 85 | 16.5% |
| 점상 + 군집성 | 52 | 25.0% |
| 무정형 + 군집성 | 93 | 37.6% |
| 다형성 + 군집성 | 453 | 45.0% |

등급과 함께 이 값을 내면 판독의에게 더 유용하다. 데이터에서 바로 나오므로
추가 학습이 필요 없다.

### 크기별 재현율 (중심 명중 · 오탐 1개/영상)

> ⚠ **옛 기준이다.** 이 표는 후처리(조직 타일 필터 · 깊이 가중) 이전,
> 그리고 채점기가 검출 0건 영상 31장을 분모에서 빼던 때의 값이다.
> 지금 작동점은 **종류당 오탐 2개**이고 분모도 다르다. 아래 숫자를
> 지금 성능으로 인용하면 안 된다. 크기별 분해는 **다시 재야 한다.**

| 구간 | 화면비율 중앙 | 종괴 | 미세석회 |
|---|---|---|---|
| 작은 1/3 | 0.10~0.24% | 66.7% | 25.2% |

| 큰 1/3 | 1.08~2.59% | 52.6% | 11.4% |

작은 병변이 더 잘 잡힌다. 석회의 경우 큰 박스는 넓게 퍼진 분포(지역성·미만성)에
해당하며 단위 면적당 알갱이 밀도가 낮다는 설명이 유력하나, **아직 측정으로
확인하지 않았다.**

지금 기준의 전체 값은 이렇다 (중심 명중 · 종류당 오탐).

| | 0.25 | 0.5 | 1 | **2 (운영점)** | 4 | 최대 |
|---|---|---|---|---|---|---|
| 미세석회 | 31.5 | 46.9 | 63.7 | **77.5** | 83.9 | 94.9 |
| 종괴 | 36.0 | 52.3 | 66.0 | **76.7** | 84.3 | 95.3 |

**맨 오른쪽 칸이 핵심이다.** 찾는 능력은 이미 95%다. 병변은 거의 다 검출
목록 안에 들어와 있고, 문제는 그것을 위로 올리지 못하는 것이다.

## 4. 원인 진단 — 전처리에서 신호를 잃고 있었다

검출용 데이터를 만들 때 원본(긴 변 약 5,200px)을 1008로 줄였다. 5배 축소다.

| | 실제 크기 | 원본에서 | 축소 후 |
|---|---|---|---|
| 종괴 | 1~3cm | 200~600px | 40~120px — 덩어리로 남는다 |
| 미세석회 낱개 | 0.2~0.5mm | 4~10px | **1~2px — 사라진다** |

병변 자리와 같은 크기의 정상 조직을 비교해 작고 밝은 알갱이가 몇 배 더 많은지
쟀다(탑햇 변환).

| 단계 | 미세석회 | 종괴 |
|---|---|---|
| 원본 해상도 | x1.75 | x1.72 |
| 1008로 축소 | x1.12 | x1.59 |
| 실제 학습 영상 (독립 표본) | x1.08 | — |

**석회는 대조군 대비 초과분의 84%를 잃고 종괴는 18%만 잃는다.**

직접 축소해 얻은 값(1.12)과 실제 학습 영상에서 잰 값(1.08)이 일치한다. 서로 다른
경로, 서로 다른 표본이므로 측정을 신뢰할 수 있다.

### 결정적 근거

**같은 백본이 서술어 시스템에서는 석회를 잘 다룬다** — 민감도 98.2%. 서술어
시스템은 원본 해상도 병변 조각을 입력으로 받고 축소를 거치지 않는다.

모델이 석회를 못 보는 것이 아니라, 검출용 데이터를 만들 때 지워서 준 것이다.

## 5. 조치와 검증

전체를 줄이는 대신 **원본 해상도에서 1008 타일로 자른다.** 화소 간격이 그대로라
알갱이가 남는다.

| | 타일 | 병변 | 양성 : 음성 |
|---|---|---|---|
| 학습 | 7,857 | 4,204 (종괴 1,918 · 석회 2,286) | 3,960 : 3,897 |
| 검증 | 2,129 | 1,094 (종괴 574 · 석회 520) | 1,069 : 1,060 |

### 검증

타일은 원본의 잘라내기이므로 리샘플링이 없어야 한다. 화소 단위로 직접 대조했다.

```
비교한 타일 367장   완전히 일치 367장   최대 화소 차이 0 (0~255 척도)
```

신호를 다시 쟀다(병변 150건, 대조는 같은 타일 안 같은 크기 창의 중앙값).

| 단계 | 미세석회 |
|---|---|
| 1008 축소 — 지금까지 학습한 데이터 | x1.12 |
| **1008 타일** | **x1.85** |

**학습 재료가 돌아왔다.** 다만 재료의 확인이지 성능의 확인이 아니다.

### 부수 효과 — 정상 조직 표본

기존 학습 데이터는 2,220장 전부에 병변이 있어 검출기가 "어딘가에 반드시 있다"를
전제로 배웠다. 타일로 자르니 같은 영상·같은 촬영 장비에서 나온 정상 조직 타일
3,897장을 얻었다. 다른 데이터셋의 정상 영상을 섞을 때 생기는 함정이 없다.

| (상한) | 74.0% | **99.4%** | 74.7% | **99.7%** |

**IoU > 0.3 기준** (박스 정확도까지 요구)

| 영상당 오탐 | 석회 기준선 | 석회 타일 | 종괴 기준선 | 종괴 타일 |
|---|---|---|---|---|
| 1.0 | 12.9% | **37.6%** | 57.0% | 54.7% |
| 4.0 | 25.7% | **62.7%** | 61.0% | **78.2%** |

### 미세석회 — 3.1배

오탐 1개/영상에서 18.6% → **57.9%**, 4개에서 37.3% → **83.3%** 다.
박스 정확도를 요구하는 IoU 기준에서도 12.9% → 37.6% 로 2.9배다.

**진단이 맞았음이 성능으로 확인됐다.** 축소로 신호의 84% 를 잃고 있었고,
원본 해상도 타일로 되살리니 검출이 따라 올라왔다.

### 종괴 — 기준선과 같아졌고, 높은 오탐에서 앞선다

```
1.0 FP   57.3%  →  56.4%     사실상 같다
2.0 FP   59.6%  →  70.3%
4.0 FP   61.3%  →  79.9%
(상한)   74.7%  →  99.7%
```

**이전 판의 정정** — 여기에 "종괴는 낮은 오탐에서 나빠졌다(48.3%)" 고
적고, 원인을 "타일이 유방 전체 맥락을 잘라내서" 라고 설명했다. **그 설명이
주된 원인이 아니었다.** 조직 밖 박스(각인 글자·피부 마커·영상 가장자리)가
낮은 오탐 예산을 잡아먹고 있었다. 그것을 거르니 48.3% → 56.4% 로 올라
기준선과 같아졌다. 맥락 손실이 없다는 뜻은 아니지만 크기가 다르다.

**최대 재현율은 74.7% → 99.7% 다.** 오탐을 무제한 허용하면 타일 모델은
병변을 거의 다 찾고, 기준선은 74.7% 에서 막힌다. 미세석회도 74.0% → 99.4% 다.
**병변이 후보 목록 안에는 들어 있고 문제는 순위다.**

다만 곡선 끝은 영상당 오탐 1,000개 수준이라 임상적 의미는 없고, 타일 모델은
질의 자리가 영상당 6,200개·기준선은 200개라 후보 수 자체가 다르다.
'후보에는 들어 있다' 는 사실만 읽어야 한다.

### 후처리로 얻은 것 — 재학습 없이

| | 석회 1FP | 종괴 1FP | 끝단 합계 |
|---|---|---|---|
| nms@0.3 · 필터 없음 | 50.2% | 48.3% | 52.5% |
| wbf@0.3 | 50.5% | 48.8% | 55.3% |
| **wbf@0.3 + 조직 필터** | **57.9%** | **56.4%** | **61.7%** |

조직 필터가 합치기 방식보다 효과가 컸다. 박스의 **20.6%** 가 조직 밖이었다
(석회 28,758 · 종괴 45,308 / 358,800).

**정탐도 조금 잃었다.** `AR100` 이 종괴 0.317 → 0.308, 석회 0.172 → 0.166 으로
내려갔고 석회 4FP 도 84.2% → 83.3% 다. 조직 경계에 걸친 병변 일부가 필터에
걸린다. 낮은 오탐 구간의 +7%p 에 비하면 작지만 공짜는 아니다.

### COCO mAP

확정 운영점(wbf@0.3 + 조직 필터) 기준.

| | mAP | AP50 | AP75 | AR100 |
|---|---|---|---|---|
| 종괴 기준선 | 0.157 | 0.370 | 0.088 | 0.337 |
| **종괴 타일** | 0.059 | 0.177 | 0.019 | 0.308 |
| 석회 기준선 | 0.002 | 0.008 | 0.000 | 0.162 |
| **석회 타일** | 0.009 | 0.037 | 0.001 | 0.166 |

석회는 AP50 이 4.6배(0.008 → 0.037). 종괴는 기준선(0.370)에 못 미친다.

**후처리 개선이 여기에도 나타난다** — 종괴 AP50 이 필터 전 0.144 에서
0.177 로 올랐다(+23%). AP75 도 0.016 → 0.019 로 함께 올랐다.

**AP75 가 기준선(0.088)의 5분의 1인 것은 조직 필터 탓이 아니라 합치기 방식
탓이다.** 점수 가중 평균이 박스를 덩어리 중심으로 끌어당겨 **느슨한 겹침에서는
더 맞고 빡빡한 겹침에서는 흐려진다** — nms 0.022 에서 wbf 0.016 으로 내려간
구간이 그것이다. 조직 필터는 거기서 다시 0.019 로 올린 쪽이다.

**우리에게는 AP50 이 맞는 지표다.** 박스에 20px 를 붙여 잘라 1008 로 늘려
서술어에 넣으므로, 병변이 조각 안에 들어오고 대략 가운데 있으면 된다.
경계선이 IoU 0.75 안에 들 필요가 없고, 실제로 AP75 가 내려간 설정이
끝단 성능을 올렸다.

**석회 mAP 가 0.009 인 것은 구조적이다.** 미세석회 정답 박스는 흩어진 알갱이를
판독의가 임의로 감싼 영역이라 그 경계를 국소 증거로 맞추는 것 자체가 어렵다.
맘모그래피 CAD 가 mAP 대신 FROC 을 쓰는 이유다.

**선행 연구와의 직접 비교는 하지 않는다.** CBIS-DDSM 검출 과제의 비교 가능한
수치를 확보하지 못했고, 프로토콜(분할·지표·명중 기준)이 다르면 숫자만 옮기는
것이 오히려 틀린 주장이 된다.

## 6-2. 끝에서 끝까지 — 두 시스템을 이었다

```
원본 사진 → 검출기 → 박스 → 잘라내기 → 서술어 → 규칙표 → 등급 → 조직검사 여부
```

같은 598명에서 두 경로를 나란히 돌린다. 병변 655건, 그중 조직검사 대상 459건.
**서빙과 같은 조건**으로 넘긴다 — 종류별 점수 임계값으로 자르고 개수는
제한하지 않는다. 작동점은 종류당 오탐 2개/영상.

| | 조직검사 대상 | ① 위치를 알려줬을 때 | ② 스스로 찾았을 때 |
|---|---|---|---|
| 미세석회 | 216 | 98.1% | **77.3%** |
| 종괴 | 243 | 82.7% | **63.8%** |
| **합계** | **459** | **90.0%** | **70.2%** |

두 종류의 영상 집합이 겹치지 않는다(석회 271장 + 종괴 327장 = 598장). 그래서
합계는 단순 합이다.

재학습 없이 후처리와 작동점만 바꿔 얻은 결과다.

```
52.5%   출발 (nms@0.3 · 필터 없음)
55.3%   겹침 합치기를 wbf@0.3 으로
61.7%   + 조직 밖 박스를 거름
```

⚠ **위 세 줄은 채점 조건이 지금과 다르다.** 임계값을 안 걸고 영상·종류당
상위 2개만 넘긴 값이라 서빙 동작이 아니고, 아래 값과 그대로 이어 붙이면 안 된다.

서빙과 같은 조건(임계값으로 자르고 개수 제한 없음)으로 다시 재면

```
60.3%   오탐 1개/영상    + 조직 타일 필터 30% · 깊이 가중
70.2%   종류당 오탐 2개  ← 지금. 작동점을 옮겼다
```

두 단계의 성격이 다르다. 후처리는 **같은 자리를 다르게 재서** 얻었고
(같은 오탐 1개 지점에서 석회 57.9→63.7% · 종괴 56.4→66.0%),
작동점 이동은 **오탐을 더 받기로 해서** 얻었다.

### 손실이 어디서 나는가 — 가정 없이 나뉜다

조직검사 대상 병변에 한정해 재면 항등식이 성립한다.

```
끝단 민감도 = (조직검사 대상 중 검출된 비율) × (검출된 것 중 옳게 판단한 비율)
```

| | 검출기 몫 | 서술어 몫 | 곱 |
|---|---|---|---|
| 미세석회 | 80.1% (173/216) | 96.5% (167/173) | 77.3% |
| 종괴 | 79.4% (193/243) | 80.3% (155/193) | 63.8% |
| **합계** | **79.7%** (366/459) | **88.0%** (322/366) | **70.2%** |

```
90.0%  ──검출 단계──▶  71.7%  ──박스 품질──▶  70.2%
          -18.3%p                -1.5%p
```

**손실의 92% 가 검출 단계에서 생긴다.** 서술어가 나빠져서가 아니라 검출기가
병변을 못 찾아서다. 그래서 작업이 전부 검출에 집중됐다.

미세석회는 서술어 몫이 **96.5%** 로, 정답 박스를 줬을 때(98.1%)에 **1.6%p**
까지 붙었다. **검출 박스로도 서술어가 사실상 같은 판단을 한다.** 종괴는
80.3% 대 82.7% 로 2.4%p 차이가 남아 있다 — 모양·경계가 윤곽의 기하라 박스에
더 민감하기 때문이다.

**상자 품질이 성능을 거의 안 깎는다**는 것이 이 두 줄의 뜻이다. 상자를
20화소 넓혀 오린 뒤 모델 입력 크기로 늘리기 때문에, 미세석회처럼 상자가
정답의 절반이어도 병변이 조각 안에 들어온다. 그래서 미세석회를 크기 주장
없는 표식으로 바꿔도 등급 판정에는 영향이 없다.

### 사슬 전체 — 세 단계

2절의 규칙표 상한까지 붙이면 어디서 얼마를 잃는지가 끝까지 갈린다.

| | 규칙표 상한 | 서술어 모델 | + 검출까지 |
|---|---|---|---|
| 미세석회 | 100.0% | 98.2% | **77.3%** |
| 종괴 | 85.2% | 82.8% | **63.8%** |
| **합계** | **92.2%** | **90.0%** | **70.2%** |

```
92.2%  ──서술어 예측 -2.2%p──▶  90.0%  ──검출 -19.8%p──▶  70.2%
```

**세 단계 중 두 번째가 가장 작다.** 서술어 모델은 규칙표가 낼 수 있는 값의
거의 전부를 뽑아내고 있다. 남은 여지는 첫 단계(규칙표 자체 — BI-RADS 어휘집의
한계라 우리가 못 고친다)와 셋째 단계(검출 — 고칠 수 있고 실제로 고치고 있다)에
있다.

### 두 코드 경로가 독립적으로 같은 답을 냈다

| | `eval_e2e.py` (CBIS ROI 파일) | `eval_end2end.py` (원본에서 잘라냄) |
|---|---|---|
| 미세석회 민감도 | 98.2% | 98.1% |
| 종괴 민감도 | 82.8% | 82.7% |

한쪽은 CBIS 가 준 조각을 그대로 읽고, 다른 쪽은 원본에서 '마스크 상자 + 20px'
로 직접 잘라낸다. 코드도 데이터 경로도 다른데 답이 같다. **자르기 재현이
맞았다는 확인이 서로 다른 방식으로 두 번 된 것이다.**

### 두 종류가 다르게 실패한다

정답 박스 대신 검출 박스를 넣으면 서술어 몫이 이만큼 떨어진다.

| | 정답 박스 | 검출 박스 | 낙폭 |
|---|---|---|---|
| 미세석회 | 98.1% | 91.6% | -6.5%p |
| 종괴 | 82.7% | 73.5% | **-9.2%p** |

종괴가 박스 오차에 더 약하다. 종괴 서술어는 **모양**(둥근·난원형·불규칙)과
**경계**(명확·미세분엽·침상)로, 둘 다 병변 윤곽의 기하다. 박스가 어긋나면
조각이 종괴를 다르게 잘라 윤곽 자체가 달라 보인다. 석회 서술어는 **형태**와
**분포** — 질감과 배치의 성질이라 몇십 화소 밀려도 남는다.

**이것이 3절의 종괴 AP75 회귀(0.088 → 0.022)와 같은 원인을 가리킨다.** 두
측정이 독립적으로 박스 품질을 지목한다. 겹침 합치기를 점수 최대에서 박스
합집합으로 바꾸는 실험이 두 지표를 동시에 건드린다.

### 검출기가 위험한 병변을 더 놓치지는 않는다

| | 전체 병변 검출률 | 조직검사 대상 검출률 |
|---|---|---|
| 미세석회 | 67.2% | 71.3% |
| 종괴 | 54.9% | 56.0% |

둘 다 조직검사 대상 쪽이 오히려 높다. 확인이 필요했던 지점이다 — 반대였다면
검출기 학습에서 어려운 병변에 가중치를 주는 작업이 필요했다. 그럴 이유가 없다.

### 박스를 몇 개 띄울 것인가 (미세석회)

| 영상·종류당 박스 | 검출률 | 끝단 민감도 | 오탐/영상 | 조직검사 오탐/영상 |
|---|---|---|---|---|
| 1개 | 46.6% | 42.1% | 0.76 | 0.48 |
| **2개** | 67.2% | **65.3%** | 1.65 | 1.07 |

하나를 더 띄우면 **민감도 +23.2%p, 불필요한 조직검사 권고 +0.59개/영상**이다.
암을 놓치는 비용이 추가 검사보다 훨씬 크므로 2개를 운영점으로 쓴다.

이 오탐 수치는 **넘길 박스 수를 우리가 정한 결과**이지 모델의 오탐률이 아니다.
2개 설정에서는 모든 영상이 정확히 2개를 내놓는다(정탐 209 + 오탐 987 = 598×2).
발표에 오탐률을 쓰려면 FROC 곡선의 특정 지점에서 점수 임계값으로 다시 재야 한다.

### 자르기 규칙 — 이 연결이 성립하는 근거

서술어 모델은 우리가 자른 조각이 아니라 **CBIS 가 같이 준 ROI DICOM** 으로
학습됐다. 검출 박스를 그 조각과 다르게 자르면 서술어가 학습 때와 다른 입력을
받고, 그러면 "연결하니 나빠졌다"는 틀린 결론이 나온다.

조각과 마스크 상자를 235건에서 직접 대조해 규칙을 쟀다.

```
규칙        마스크 상자의 각 변에 20px        (10~90퍼 20~20 · 상하 표준편차 0.00)
정렬        가운데                            (좌우·상하 비대칭 0.0px)
검증        정규화 후 일치 235/235 (100%)     정합 점수 1.000
```

**그리고 성능으로 확인됐다.** 서술어를 ROI 파일로 쟀을 때 석회 민감도가 98.2%
였는데, 원본에서 이 규칙으로 잘라 넣으니 98.1% 다. 자르기 재현이 맞았다.

## 6-3. 시연에서 드러난 한계 — 지표에 안 잡히던 것들

`predict.py` 로 실제 영상 6장(석회 3 · 종괴 3)을 돌리고 정답 상자를 같이
그려서 확인했다. **집계 지표로는 안 보이던 세 가지가 나왔다.**

측정치가 병변이 있는 영상에서만 잰 값이라 그렇다. 병변이 없거나 양성인
영상에 무엇을 내놓는지는 재지 않았다.

### ① 시스템이 "아니오"를 거의 말하지 않는다 — 구조적 한계

6장 전부 `조직검사 권고` 가 나왔다. 그중 하나는 **정답이 등급 2
(BENIGN_WITHOUT_CALLBACK, 추적조차 불필요)** 인데 조직검사로 보냈다.
석회 검출 6건의 등급이 예외 없이 4였다.

**원인은 학습 데이터에 있다.** 서술어 모델은 CBIS 병변 조각으로만 배웠고,
그 조각은 전부 조직검사가 확정된 이상 소견이다. **정상 조직을 본 적이 없고
'소견 없음' 이라는 출력 자체가 없다.** 어떤 조각을 넣어도 이상 소견 어휘
중 하나를 고르게 되고, 석회 쪽 최다 조합은 BI-RADS 4 로 간다.

이 시스템은 **"병변이 주어졌을 때 기술한다"** 로 설계됐지 **"이것이
병변인가"** 를 묻도록 설계되지 않았다. 검출기가 오탐을 내면 서술어가 그것을
걸러낼 방법이 없다. 2절의 `'전부 조직검사' 기준선 69.6%` 경고가 가리키던
것의 정체가 이것이다.

**해결 가능하다 — 다음 과제다.** 타일 작업에서 **정상 조직 타일 3,897장**을
이미 만들어뒀다(5절). 그것을 서술어 학습에 '소견 없음' 클래스로 넣으면
된다. 데이터가 이미 있고 같은 영상·같은 장비에서 나온 것이라 촬영 방식을
구분하게 되는 함정도 없다.

### ② 종류 판별이 불안정하다

종괴 영상 3장 모두에서 **미세석회 질의가 종괴 위에서 높은 점수를 냈다.**
위치는 맞히고 종류를 틀린다. 그러면 잘못된 서술어 모델로 들어간다.

```
정답: 종괴 B5 MALIGNANT
검출: "미세석회" 0.73  →  석회 서술어 모델  →  BI-RADS 4  →  조직검사
```

최종 판단은 맞았지만 경로가 틀렸다. 종괴 서술어 모델은 쓰이지도 않았다.

SAM 3 는 맘모그래피를 배운 적이 없고 `"mass"` 와 `"calcification"` 을 의료
영상의 병변 종류로 구분하도록 학습된 적도 없다. LoRA 6에폭으로는 그 구분이
붙지 않았다. **검증 방법**: 같은 병변에 두 질의의 점수를 나란히 재면 확인된다.

### ③ 조직 밖 오탐이 있었다 — 해결함

각인 글자(`RCC`), 피부 마커(금속 구슬), 영상 가장자리 공기 영역에 박스가
붙었다. 대비가 극단적이라 검출기가 끌린다. `tissue_mask` 로 조직 영역을
이미 계산하고 있었는데 **박스를 그것으로 거르지 않고 있었다.**

박스 면적의 50% 이상이 조직이어야 남기는 필터를 넣었다. 6장 중 3장에서
1개씩 걸러졌다. 병변은 정의상 조직 안에 있으므로 정탐을 버리지 않는다.

**측정했다.** 전체 검출 박스의 **20.6%** 가 조직 밖이었다(석회 28,758 ·
종괴 45,308 / 358,800). 그것을 거르니 오탐 1개/영상 기준 민감도가
**석회 +7.4%p · 종괴 +7.6%p**, 끝단이 **55.3% → 61.7%** 로 올랐다.

**지금까지의 모든 오탐 측정이 이만큼 부풀려져 있었다.** 6절의 수치는
필터를 적용한 값으로 갱신했다.

### 종괴 임계값에 관한 실무 사항

FROC 오탐 0.25개/영상 지점의 종괴 임계값이 **0.822** 인데 실제 영상에서 나온
종괴 점수 상한이 **0.816** 이었다. 그 설정에서는 종괴 검출이 하나도 안 남는다
— 정답이 악성 종괴인 영상 3장에서도 0건이었다.

**당시 운영점은 오탐 1개/영상(석회 0.594 · 종괴 0.767)이었다.** 그 설정에서
종괴 3장 모두 검출이 살아났고, 그중 하나는 정답 상자와 거의 정확히 겹쳤다.

> ⚠ **지금 운영점은 종류당 오탐 2개이고 임계값은 석회 0.448 · 종괴 0.462 다.**
> 후처리(조직 타일 필터 · 깊이 가중)를 넣으면서 점수 눈금이 바뀌었다.
> 옛 임계값을 그대로 쓰면 문턱이 너무 높아 검출이 확 줄어든다.

## 6-4. 후처리는 더 나올 것이 없다 — 시험한 7가지가 전부 나빠졌다

6절의 개선(wbf + 조직 필터)이 재학습 없이 나왔으므로, 같은 방향으로 더 짜낼
것이 있는지 끝까지 확인했다. **없었다.** 그 확인 자체가 결과다 — "아직 안 해본
것이 남아 있다" 와 "다 해봤고 현행이 최선이다" 는 전혀 다른 말이다.

### 재순위 — 7가지 전부 나빠졌다

문제는 이것이었다. 타일마다 점수를 독립적으로 매기므로 **쉬운 타일의 자신 있는
오탐이 어려운 타일의 정탐 위에 올라간다.** 순위만 바로잡아도 같은 오탐 예산에서
민감도가 오를 여지가 있어 보였다. `rerank.py` 로 저장된 검출 JSON 만 가지고
시험했다(GPU 불필요).

| 방식 | 근거 | 결과 |
|---|---|---|
| 타일 합의 (agree · α 3종) | 여러 타일이 같이 잡은 박스일수록 참일 것이다 | 전부 나빠짐 |
| 좁은 박스 우선 (tight) | 타일 경계에서 잘린 박스는 넓게 퍼진다 | 나빠짐 |
| 평균 점수 (meanscore) | 최대 대신 덩어리 평균이 안정적일 것이다 | 나빠짐 |

**양방향 다 시도했다.** 가중치 부호를 뒤집어도 나빠졌다. 기준선을 정확히
재현한 상태에서 잰 값이라(@1FP 석회 57.9% · 종괴 56.4%, −0.0%p) 구현 실수가
아니다.

**왜 안 되는지도 나왔다.** 덩어리 크기가 **합의가 아니라 모호함**을 잰다.
덩어리에 박스가 많다는 것은 여러 타일이 동의했다는 뜻이 아니라, 경계가
불분명해 제각각 잡았다는 뜻이다. 석회는 덩어리당 중앙 4개 · 최대 60개,
종괴는 중앙 3개 · 최대 67개다. 최대값이 저렇게 큰 것이 그 근거다.

### 조직 상자 교체 — 병변을 자른다

조직 상자를 마스크 전체의 최소·최대로 잡으므로 필름 구석의 밝은 점 하나가
상자를 영상 전체로 늘린다. 시연에서 실제로 3826×6601 영상의 조직 상자가
[0,0,3826,6601] 이었다 — 타일 45장 중 상당수가 공기만 훑었다.

가장 큰 연결 요소만 남기는 안을 `check_tissue_bbox.py` 로 쟀다.

| | 값 |
|---|---|
| 현행 상자가 영상의 90% 를 넘는 경우 | 영상의 **90%** |
| 타일 감소 | **13%** 뿐 |
| **정답 병변이 새 상자 밖으로 나가는 경우** | 영상 60장에서 **2건** |

**채택하지 않는다.** 민감도를 깎으면서 속도만 얻는 거래다. 게다가 정확도
이득은 이미 조직 *필터* 가 가져갔다(6-3절 ③) — 상자를 줄이는 것은 계산량만
아낀다. 상자를 바꾸면 훑는 영역이 바뀌어 **지금까지의 검출 수치가 전부 무효**가
되는 것까지 감안하면 값어치가 없다.

### 그래서 남은 것은 재학습뿐이다 — 이 판단은 뒤에 정정됐다

후처리로 얻을 수 있는 것은 wbf + 조직 필터에서 끝났다(끝단 52.5% → 61.7%).
더 올리려면 검출기를 다시 학습해야 하고, 그것은 이번 일정 안에서 하지 않기로
했다(10절).

> **정정 (2026-09-04).** 후처리가 끝난 것이 아니었다. **유방 깊이 가중**을
> 더 얹어 FROC 이 석회 63.7→77.5 · 종괴 66.0→76.7 로 올랐다(작동점 이동 포함).
> 깊이는 조직 마스크와 같은 종류의 정보다 — 검출기가 안 보는 바깥 정보.
>
> **정정 (2026-09-06).** 재학습도 해 봤고 기각했다. 에폭 12 는 과적합이었다.
> 그 뒤 순위를 올리는 시도를 열둘까지 했고 성공은 둘이다. 10절 참조.

### 7-1. 외부 검증 결과 — VinDr-Mammo

CBIS로 학습한 검출기를 **한 번도 안 본 데이터셋**에 그대로 걸었다.
운영점·후처리·FROC 코드를 CBIS와 똑같이 맞췄다. 재학습·재조정 없음.

측정 대상 435장 · 미세석회 511건 · 종괴 230건.

> ⚠ 아래 표는 **후처리 이전 · 운영점 오탐 1개** 기준의 기록이다.
> 지금 기준(조직 타일 필터 30% + 깊이 가중 · 종류당 오탐 2개)의 값은
> 표 뒤에 따로 적었다.

| 오탐/영상 | 미세석회 CBIS → VinDr | 종괴 CBIS → VinDr |
|---|---|---|
| 0.25 | 21.5% → 23.9% (+2.4) | 26.2% → 15.7% (−10.5) |
| 0.5 | 39.2% → 35.4% (−3.8) | 38.7% → 25.7% (−13.0) |
| **1.0 (당시 운영점)** | **57.9% → 43.2% (−14.7)** | **56.4% → 41.7% (−14.7)** |
| 2.0 | 74.3% → 57.3% (−17.0) | 70.3% → 60.0% (−10.3) |
| 4.0 | 83.3% → 66.5% (−16.8) | 79.9% → 73.9% (−6.0) |

**당시 운영점에서 두 종류가 정확히 같은 폭(−14.7%p)으로 떨어졌다.**

### 지금 기준의 값 — 그리고 낙폭보다 중요한 것

같은 가중치에 CBIS 와 똑같은 후처리를 걸고 종류당 오탐 2개에서 다시 쟀다.

| | CBIS | VinDr | 낙폭 |
|---|---|---|---|
| 미세석회 | 77.5% | **60.3%** | −17.2 |
| 종괴 | 76.7% | **63.9%** | −12.8 |

낙폭은 여전히 크다. 그런데 **최대 재현율을 같이 보면 이야기가 달라진다.**

| 종괴 최대 재현율 | |
|---|---|
| CBIS | 95.3% |
| **VinDr** | **96.1%** |

**VinDr 에서 오히려 더 높다.** 병변이 안 보이는 것이 아니다. 검출 목록 안에는
CBIS 보다도 더 많이 들어와 있고, **순위를 못 매기는 것**이다.

> **영역 차이는 「찾기」의 문제가 아니라 「고르기」의 문제다.**
> 발표에서 낙폭을 말할 때 이 문장을 같이 붙일 것. 모델이 다른 병원 영상을
> 못 본다는 뜻이 아니라, 무엇을 먼저 보여줄지의 기준이 데이터셋마다
> 다르다는 뜻이다.

### 예측이 빗나갔다

실행 전에 "미세석회가 크게 떨어지고 종괴는 덜 떨어진다"고 적어 두었다.
VinDr이 **대체로** 0.085mm/px라 낱개 미세석회가 2.4~5.9px로 찍히고, CBIS에서는
4.6~11.5px였다는 근거였다. **틀렸다.** 운영점에서 하락 폭이 같았고,
낮은 오탐(0.25)에서는 오히려 미세석회가 올랐다.

### 더 그럴듯한 설명 — 정답의 정의가 다르다

| | CBIS-DDSM | VinDr-Mammo |
|---|---|---|
| 정답 근거 | **조직검사로 확정** | 판독의가 **표시**만 함 |
| 따라서 | 평균적으로 더 뚜렷한 병변 | 미묘한 소견이 섞임 |

우리 검출기는 조직검사까지 간 병변만 보고 배웠다. 이 차이는 종괴와 미세석회에
**똑같이** 작용하므로 균일한 하락과 맞는다. 해상도 가설은 종류별로 다른 하락을
예측하는데 그렇지 않았다.

한 가지 더 — VinDr은 유방이 화면의 17.2%(CBIS 40.9%)라 영상당 타일이 적다.
오탐 기회가 적으니 같은 오탐/영상에 도달하기가 **더 쉽다.**
즉 이 격차는 타일 수로 설명되지 않고, 오히려 과소평가됐을 수 있다.

### 화소 간격은 한 값이 아니다 — 기종이 섞여 있다

서비스 파이프라인에 DICOM 머리말 파싱을 붙이면서 **443장 전부의 화소 간격을
실제로 읽었다**(2026-09-01). 하나가 아니었다.

| 간격 | 장수 | 비율 | 촬영 기종 |
|---|---|---|---|
| 0.085 mm/px | 355 | 80.1% | Mammomat Inspiration 282 · Planmed Nuance 73 |
| 0.0814 mm/px | 81 | 18.3% | GIOTTO IMAGE 3DL |
| 0.0828 mm/px | 4 | 0.9% | GIOTTO CLASS |
| 0.083 mm/px | 3 | 0.7% | GIOTTO CLASS |

443장 전부에서 값을 읽었고 빠진 영상은 없다. **기종이 원인이다** — 간격이
장비별로 정확히 갈린다. 앞에서 "VinDr = 0.085" 로 쓴 것은 다수값(80.1%)이고
전부는 아니다.

**아래 재실험의 결론은 이 사실로 바뀌지 않는다.** 편차 폭이 0.0814~0.085 로
**4.4%** 인데 재실험에서 적용한 확대는 **42%** 다. 보정량의 10분의 1이라
방향도 크기도 흔들리지 않는다.

**다만 일괄 배율에는 한계가 있다.** 1.42배를 443장 전체에 똑같이 걸었으므로
GIOTTO 계열 88장(19.9%)은 이미 4.4% 더 촘촘한 상태에서 한 번 더 키운 셈이다.
영상별 간격으로 배율을 잡으면 회복 폭이 조금 더 커질 여지가 있다. 다만 그것은
시험셋에 맞추는 방향이라 운영점 결정에는 쓰지 않는다.

**그래서 서비스 파이프라인은 영상별로 간격을 읽는다.** 업로드 시점에 DICOM
머리말에서 `ImagerPixelSpacing`(0018,1164)을 뽑아 메타로 넘기고, 없으면
없다고 명시한다 — CBIS 처럼 필름 스캔이면 간격 자체가 없기 때문이다.
실제 VinDr 파일을 태워 0.0814 가 뽑히는 것을 확인했다(2026-09-01).

### 확대 재실험 — 원인이 갈렸다

VinDr을 1.42배로 키워(CBIS의 겉보기 배율에 맞춰) 같은 검출기로 다시 쟀다.
435장 · 같은 병변 수 · 같은 후처리.

**미세석회 (511건)**

| 오탐/영상 | CBIS | VinDr 원본 | VinDr 1.42배 |
|---|---|---|---|
| 0.25 | 21.5% | 23.9% | **30.3%** |
| 0.5 | 39.2% | 35.4% | **40.9%** |
| **1.0 (운영점)** | **57.9%** | **43.2%** | **54.6%** |
| 2.0 | 74.3% | 57.3% | **67.7%** |
| 4.0 | 83.3% | 66.5% | **76.3%** |

**종괴 (230건)**

| 오탐/영상 | CBIS | VinDr 원본 | VinDr 1.42배 |
|---|---|---|---|
| 0.25 | 26.2% | 15.7% | 13.0% |
| 0.5 | 38.7% | 25.7% | 17.8% |
| **1.0 (운영점)** | **56.4%** | **41.7%** | **37.4%** |
| 2.0 | 70.3% | 60.0% | 54.3% |
| 4.0 | 79.9% | 73.9% | 70.4% |

**미세석회는 해상도가 원인이다.** 운영점에서 43.2 → 54.6%, 격차 14.7%p 중
**11.4%p를 회복했다(78%).** CBIS와의 차이가 3.3%p만 남는다.

**종괴는 해상도가 아니다.** 키우니 모든 지점에서 나빠졌다(41.7 → 37.4%).
14.7%p는 여전히 설명되지 않고, 라벨 정의 차이가 남은 후보다.

미세석회의 회복은 보이는 것보다 크다. 확대하면 영상당 타일이 2배가 되고,
오탐 기회도 2배가 된다 — 같은 「오탐 1개/영상」에 도달하려면 임계값을 더
올려야 하므로 **민감도에 불리한 조건이다.** 그 역풍을 뚫고 11.4%p 올랐다.

### 판단을 두 번 정정했다

이 건은 추론 과정을 기록으로 남긴다.

1. 실행 전 — "미세석회가 더 떨어질 것이다"(화소 간격 근거). 원본 결과에서
   두 종류가 **똑같이 −14.7%p** 라 빗나간 것으로 보였다.
2. 그래서 해상도 가설을 접고 **라벨 정의 차이**로 결론냈다.
3. 확대 실험 결과 — 미세석회는 해상도가 맞았고, 종괴는 아니었다.

실제로는 **두 종류가 서로 다른 이유로 떨어졌는데 그 크기가 우연히 같았다.**
같은 숫자를 보고 같은 원인이라고 읽은 것이 2번의 오류다.

### 종류별 배율은 채택하지 않는다

미세석회만 확대해서 돌리면 둘 다 최선을 쓸 수 있다(질의를 종류별로 따로
돌리므로 구현도 어렵지 않다). 그러나 **그 배율을 VinDr 결과를 보고 정하면
시험 데이터에 맞춘 것**이 되어 외부 검증이 아니게 된다.

관찰 결과로만 기록하고 **운영점은 원본 크기 그대로 둔다.**
발표에 쓰는 수치는 재조정 없이 그대로 건 것이다.

### 이 실험의 한계

CBIS에 `PixelSpacing` 태그가 없다(표본 120장 중 0장 · 필름 스캔이라 흔하다).
1.42배는 물리 측정이 아니라 **긴 변 비율**(CBIS 4,996px · VinDr 3,518px)에서
나온 값이고, 「두 집단의 유방 크기가 평균적으로 같다」는 가정이 깔려 있다.
방향은 신뢰할 수 있지만 정확한 배율은 아니다.

### 발표에서 이 수치를 어떻게 말할 것인가

외부 검증에서 성능이 떨어지는 것은 예외가 아니라 통례다. 숨기지 않고
**−14.7%p** 를 그대로 말하는 편이 낫다. 덧붙일 것은 두 가지다.

- 재학습도 임계값 재조정도 하지 않았다. 있는 그대로 걸었다.
- 두 데이터셋의 「정답」이 같은 것을 뜻하지 않는다. 조직검사 확정과
  판독의 표시를 같은 저울에 올린 수치다.

### VinDr 라벨에 관한 정정

VinDr에는 **소견 종류와 병변 박스가 있다.** 없는 것은 BI-RADS 어휘집 서술어다.

| VinDr에 있는 것 | VinDr에 없는 것 |
|---|---|
| 소견 종류 (종괴 · 의심 석회화 · 구조 왜곡 등) | 종괴 모양 · 경계 |
| 병변 박스 좌표 | 석회 형태 · 분포 |
| 유방 단위 BI-RADS · 유방 밀도 | |

단계에 따라 쓸 수 있고 없고가 갈리는 것이지 라벨이 없는 데이터셋이 아니다.
서술어 학습에는 못 쓰고, 검출 학습·검증에는 쓸 수 있다.

실제로 걸러 보니 **영상 435장 · 정답 654행**이었다(박스 없음 0 · 다른 소견만
있는 영상 80). 한 박스에 두 종류가 붙는 경우가 있어 종류별로는
**미세석회 511건 · 종괴 230건**으로 합이 654를 넘는다.

> 정정 — 영상을 받기 전에는 "병변 543건 / 영상 442장"으로 적어 두었다.
> 라벨 CSV만 보고 센 추정치였고, 실제 파일과 대조하니 위 숫자가 맞다.

### 섞을 때 주의

CBIS는 1990년대 필름 스캔이고 VinDr은 디지털 직접 촬영이다. 한쪽을 전부 양성,
다른 쪽을 전부 음성으로 넣으면 검출기가 병변이 아니라 촬영 방식을 구분하는 법을
배운다. 학습 손실은 정상적으로 떨어지므로 발견하기 어렵다.

## 7-2. 정상 검사 실측 — VinDr BI-RADS 1 (2026-09-08)

지금까지의 모든 수치는 **병변이 있는 영상**에서 나왔다. 학습·평가에 쓴 CBIS-DDSM 은
조직검사가 확정된 사례만 모은 자료라 정상 영상이 **598장 중 0장**이다. 검진에서는
대부분이 정상인데, 거기서 이 시스템이 무슨 말을 하는지를 한 번도 측정하지 않았다.

09-08 에 VinDr-Mammo 에서 **네 유방이 전부 BI-RADS 1 인 검사 75건 (사진 300장)**을
골라 내려받아 쟀다. 한쪽만 정상인 검사가 섞이면 반대쪽 병변을 오탐으로 세게
되므로 네 장 전부를 조건에 넣었다.

| 단위 | 표시가 하나도 없음 | 뭔가 나옴 | 조직검사 권고 |
|---|---|---|---|
| 사진 300장 | 5.3% | 94.7% | 81.0% |
| 검사 75건 | **0%** | **100%** | **100%** |

정상 여성 75명 전원이 다시 불려 오고 전원이 조직검사 권고를 받는다. 영상당 표시는
**2.30개**(종괴 1.70 · 석회 0.60)다.

**이것은 모델의 고장이 아니다.** 작동점이 영상당 4개까지 허용한 값이고(종류당
2개 × 두 종류) 실측이 2.30 이다 — 우리가 정한 예산 안이며, 오히려 CBIS 기준보다
조용하다. 사진 한 장이 조용할 확률 5.3% → 네 장이 모두 조용할 확률
0.053⁴ ≈ 0.0008%. 0/75 는 우연이 아니라 §0 의 "검사 하나 = 네 장" 전제에서
이미 정해진 값이다. **사진 단위만 보면 실제보다 훨씬 좋아 보인다.**

### 문턱을 올리면 되나 — 안 된다

양쪽 다 VinDr 로 재서 자료가 섞이는 문제를 없앴다(양성 435장 / 정상 300장).
병변 100건 · 정상 여성 100명 기준 · 검출 단계 · 중심 명중.

| 문턱 | 석회 찾음 | 종괴 찾음 | 정상인데 부름 | 정상인데 조직검사 |
|---|---|---|---|---|
| **0.45 (지금)** | 43건 | 59건 | 100명 | 100명 |
| 0.55 | 26건 | 41건 | 91명 | 84명 |
| 0.60 | 16건 | 32건 | 53명 | 43명 |
| 0.70 | 2건 | 6건 | 11명 | 4명 |
| 0.75 | 0건 | 1건 | 0명 | 0명 |

정상 재소환이 검진 수준(11명)까지 내려가는 문턱에서 병변은 100건 중 2~6건밖에
못 찾는다. **정상 유방의 헛표시와 진짜 병변의 점수 분포가 거의 겹친다** — 선을
어디에 그어도 쓸 수 있는 지점이 없다. 문턱의 문제가 아니다.

### 결론 — 용도를 다시 말해야 한다

| 아니다 — 검진 선별기 | 맞다 — 판독 보조기 |
|---|---|
| 정상 여성을 걸러 내는 물건이 아니다. 측정으로 확인했고, 문턱을 올려도 안 된다는 것까지 확인했다 | 판독의가 이미 보고 있는 영상에 표시를 얹는다. 표시가 여러 개 뜨는 것을 전제로 쓴다 |

**작동점(종류당 오탐 2개)은 바꾸지 않는다.** 판독 보조로는 맞는 선택이다. 바꿔야
하는 것은 값이 아니라 **이 시스템이 무엇에 쓰이는지에 대한 말**이다. 응답의 고지
문구에 헛표시 쪽 경고를 추가했다 — 그전까지는 놓치는 쪽만 경고하고 있어서
"표시가 떴다 = 뭔가 있다"로 읽힐 수 있었다.

## 9. 예상 질문과 답

### "mAP가 얼마인가"

> 현재 모델이 종괴 0.059, 미세석회 0.009입니다. AP50 으로는 0.177 과 0.037 입니다.
> 낮습니다. 다만 저희가 앞에 두는 지표는 mAP 가 아니라 FROC 입니다.
> 맘모그래피 CAD 가 FROC 을 쓰는 이유는, 미세석회 정답 박스가 흩어진 석회를
> 판독의가 임의로 감싼 영역이라 IoU 0.75 를 요구하는 것 자체가 임상적으로
> 의미가 없기 때문입니다. 판독의에게 중요한 것은 경계선이 아니라 위치입니다.

**따라오는 질문에 대비할 것 — "기준선보다 종괴가 내려간 것 아닌가"**

> 맞습니다. 종괴 AP50 이 0.370 에서 0.177 로 내려갔습니다.
> 다만 AR100 은 0.337 에서 0.308 입니다. 찾아내는 양은 9% 줄었고
> 나머지는 순위와 박스 정확도가 나빠진 것입니다. AP75 가 5분의 1인 것이
> 근거입니다.
> 원인 셋을 특정했습니다. 타일마다 점수를 독립적으로 매겨 서로 비교가 안 되는 것,
> 종괴가 타일 경계에서 잘리는 것, 그리고 기준선이 838M 전체 미세조정 20에폭인 데
> 비해 이쪽은 LoRA 11M 6에폭이라 학습 예산이 다른 것입니다.
> 앞의 둘은 저장된 검출 결과만으로 후처리 실험이 가능하고, 셋째는 재학습으로 답합니다.

**주의** — 비교 가능한 선행 연구 수치를 아직 확보하지 못했다. 확보 전에는
"문헌 대비 어느 수준"이라고 말하지 않는다.

### "정상인 사람을 넣으면 뭐라고 하나"

> 지금은 대부분 조직검사 권고가 나옵니다. 실제 영상 6장으로 확인했고,
> 정답이 확정 양성인 영상도 조직검사로 보냈습니다.
> 원인은 학습 데이터입니다. 서술어 모델은 조직검사가 확정된 병변 조각으로만
> 배웠고 정상 조직을 본 적이 없습니다. '소견 없음' 이라는 출력 자체가 없어서
> 어떤 조각을 넣어도 이상 소견 중 하나를 고르게 됩니다.
> 해결책은 있습니다 — 타일 작업에서 나온 정상 조직 3,897장을 '소견 없음'
> 클래스로 넣어 서술어를 다시 학습하면 됩니다. 데이터는 이미 확보돼 있습니다.

**이 질문은 반드시 나온다.** 먼저 말하는 편이 낫다. 검진 도구가 아니라
'조직검사 대상 병변에 대한 판단 보조' 라는 조건을 앞에 붙여야 한다.

### "FROC이 무엇인가"

> 영상당 오탐을 몇 개까지 허용하느냐에 따라 민감도가 어떻게 변하는지 그린
> 곡선입니다. 판독의 화면에 헛 표시가 몇 개까지 참을 만한가가 실제 사용
> 조건이라 맘모그래피 CAD의 표준 지표입니다.

### "왜 YOLO를 안 썼나"

> YOLO는 검출을 처음부터 학습해야 합니다. 학습 데이터가 2,220장이라 부족합니다.
> SAM 3는 텍스트로 물체를 찾는 능력이 이미 학습돼 있습니다. 맘모그래피를 배운 적
> 없는 모델이 "mass"라는 단어만으로 종괴를 57% 찾았습니다.
> 그리고 서술어 모델이 같은 백본을 쓰므로 두 단계가 특징 공간을 공유합니다.

### "맘모그래피 전용 모델은 왜 안 썼나"

Mammo-CLIP(맘모 영상 + 판독문으로 사전학습) 을 **서로 다른 자리에서 두 번
써 봤고 두 번 다 기각했다.**

| | 언제 | 어디에 | 결과 |
|---|---|---|---|
| ① | 2026-08 | 서술어 백본 교체 | 조직검사 판단 84.7% → **84.0%** |
| ② | 2026-09-06 | 검출 재점수 | FROC 석회 **−10.6%p** · 종괴 **−4.0%p** |

②는 Mammo-CLIP 특징으로 「병변/정상」 분류기를 학습해 검출 순위를 다시
매긴 것이다. 어떤 가중치로 섞어도 원본보다 나빴다.

> 두 번 써봤고 두 번 다 측정해서 기각했습니다. 이유는 셋으로 봅니다.
>
> 첫째, **학습 목표가 다릅니다.** CLIP은 영상과 판독문을 짝지어 학습하는데,
> 판독문은 사진 한 장 전체에 대한 서술입니다. 그래서 특징이 영상 수준의
> 정보를 담게 최적화됩니다. 저희가 묻는 것은 "이 작은 조각이 병변인가"
> 라는 국소적인 질문이라 다른 문제입니다.
>
> 둘째, **모델이 15배 작습니다.** 30M 대 454M 입니다.
>
> 셋째, 같은 자료에 같은 머리를 얹어 재보니 **특징 자체가 덜 갈랐습니다.**
> 학습 AUC가 0.8775 대 0.9093 이었습니다. 배선 오류라면 0.5 근처가 나옵니다.
>
> **「맘모 전용」은 도메인이 같다는 뜻이지 과제가 같다는 뜻이 아닙니다.**

**이 실험의 한계 — 밝히고 간다.**

Mammo-CLIP 은 **1520×912 유방 전체**로 학습된 모델인데, 우리는 병변 상자를
오려 **1008 정사각으로 늘려** 넣었다. 종괴 상자가 300px 쯤이면 3배 넘게
확대된 조각이라, **Mammo-CLIP 의 학습 분포 밖이다.**

백본 하나만 바꿔야 비교가 깨끗하다는 이유로 크기를 고정했다. 방법론적으로는
맞지만 **Mammo-CLIP 쪽에 불리했을 수 있고, 크기를 맞춰 다시 재지는 않았다.**
따라서 위 결과는 「이 조건에서 안 통했다」이지 「Mammo-CLIP 이 못 쓴다」가
아니다.

> ⚠ 8월 답변에 있던 「병목이 백본이 아니라 데이터다」는 그 시점의 진단이다.
> 그 뒤 병목이 더 정확히 갈렸다 — **검출은 찾기가 아니라 순위**(최대 재현율이
> 이미 95%), **서술어는 모델이 아니라 규칙표와 판독의 등급의 구조적
> 불일치**(모델은 천장에서 0.4~4.5%p 안). 5절·10절 참조.

### "정확도 85.3%는 무슨 조건인가"

> 병변 위치가 주어진 조건입니다. 그 조건에서 미세석회 민감도가 98.1%,
> 종괴가 82.7%, 합쳐서 90.0% 입니다.
> 검출까지 포함해 끝에서 끝까지 돌리면 **70.2%** 입니다. 실측했습니다.
> 그 차이의 92% 가 검출 단계에서 생깁니다. 서술어가 나빠지는 게 아니라
> 검출기가 병변을 못 찾아서입니다. 그래서 작업이 검출에 집중돼 있습니다.

### "그럼 이 시스템의 성능은 얼마인가"

> 조건을 붙여야 정확합니다. 사진만 주면 조직검사 대상 병변의 **70.2%** 를
> 스스로 찾아 판단합니다. 위치를 알려주면 90.0% 입니다.
> 손실을 나누면 검출 단계에서 18.3%p, 박스가 정답과 달라서 1.5%p 입니다.
> **잃는 것의 92%가 검출 단계입니다.**
> 이 분해는 근사가 아니라 항등식입니다 — 조직검사 대상 병변에 한정해
> '찾은 비율 × 찾은 것 중 옳게 판단한 비율' 로 재기 때문에 가정이 없습니다.

### "종괴가 석회보다 많이 떨어지는데"

> 두 단계 모두에서 그렇습니다. 검출이 79.4% 대 80.1%, 서술어가 80.3% 대 96.5%
> 입니다. **검출은 거의 같아졌고 차이는 서술어에 남아 있습니다.**
> 서술어 쪽 차이에는 이유가 있습니다. 종괴 서술어는 모양과 경계 —
> 병변 윤곽의 기하입니다. 검출 박스가 어긋나면 조각이 종괴를 다르게 잘라
> 윤곽이 달라 보입니다. 석회 서술어는 형태와 분포라 질감의 성질이어서
> 박스가 조금 밀려도 남습니다.
> 그래서 종괴 쪽 개선은 검출을 더 찾게 하는 것보다 **박스를 더 정확하게**
> 만드는 쪽이 먼저입니다. 같은 결론이 mAP 에서도 나왔습니다 — 종괴 AP75 가
> 0.088에서 0.022로 떨어졌고, 원인이 타일 경계 잘림과 겹침 합치기 방식입니다.

### "등급 정확도가 65.8%밖에 안 되는데"

> 참고 지표입니다. 저희가 답하는 질문은 조직검사 여부이고 그쪽이 85.3%입니다.
> 그리고 서술어만으로 도달 가능한 상한이 71.9%라는 것을 측정했습니다.
> 같은 서술어 조합이 실제로 여러 등급에 걸쳐 있기 때문이며, 규칙표를 어떻게
> 고쳐도 그만큼은 맞힐 수 없습니다.

### "위치를 알려주면 90.0%라는데, 나머지 10%는 왜 못 맞히나"

2026-09-07 에 이것만 따로 쟀다. 정답 서술어를 규칙표에 **그대로** 넣어
모델을 건너뛴 값 — 서술어 방식의 천장이다.

| | 천장 | 지금 | 모델 몫 | 규칙표 몫 |
|---|---|---|---|---|
| 미세석회 | 98.5~99.1% | 98.1% | 0.4~1.0%p | 0.9~1.5%p |
| 종괴 | 85.2~87.2% | 82.7% | 2.5~4.5%p | 12.8~14.8%p |

> 나머지 10%p 의 대부분은 모델이 틀린 게 아닙니다. **서술어 기반 규칙과
> 판독의 등급의 구조적 불일치**입니다. 종괴에서 떨어지는 것의 거의 전부가
> 「경계가 뚜렷한 타원형 종괴」 한 조합인데, 그건 BI-RADS 어휘집에서
> 3등급으로 분류되는 소견입니다. 규칙표가 맞습니다.
>
> **그리고 그렇게 떨어진 병변의 74%가 조직검사 결과 양성이었습니다.**
> 판독의가 4로 올렸다가 양성으로 나온 것들입니다. 놓쳤다기보다
> 불필요한 조직검사를 피한 쪽에 가깝습니다.

> 규칙을 풀어 이것들을 잡을 수는 있습니다. 다만 같은 규칙이 추적으로
> 충분한 병변까지 올립니다 — 그 대가를 재 보니 **암 11건을 더 잡으려고
> 양성 53명을 조직검사대에 올리는** 교환이었고, 그래서 하지 않았습니다.

### "성능을 더 올릴 방법은 없나"

> 순위를 올리려고 **12가지를 시도해서 2개가 성공했습니다.** 실패한 것도
> 전부 기록에 남겨 뒀습니다. 거기서 규칙이 하나 나왔습니다.
>
> **검출기가 못 보는 정보 중에서, 정탐과 오탐이 다르게 나타나는 것을
> 넣어야 순위가 오릅니다.**
>
> 성공한 둘(조직 마스크 · 유방 깊이)은 오탐이 유방 경계선에 몰려 있다는
> 것을 이용했습니다. 실패한 것들은 검출기가 이미 본 정보를 재배열했거나
> — 이진 분류기가 그랬습니다, 같은 백본을 썼으니까요 — 바깥 정보이긴 한데
> 정탐과 오탐이 똑같이 나타나는 것이었습니다. CC·MLO 두 시야 일치가
> 그랬습니다. **헛것도 두 시야에 같이 나타납니다.**

그 정보에서 **정탐과 오탐의 분포가 실제로 갈렸다**. 실패한 열은 둘 중 하나가

조직이 겹쳐 생긴 오탐은 그 유방의 실제 구조라 각도를 바꿔도 따라온다.

### 다음 지렛대 (2026-08-31 기록 — 아래는 그때의 판단이다)

**박스 품질.** 세 측정이 같은 곳을 가리킨다 — 종괴 AP75 0.088→0.022, 종괴가

**결과: 점수 가중 평균(wbf)이 현행 NMS 보다 낫다.** 같은 파일에서 잰 값이다.
**아래 표는 조직 필터를 넣기 전 값이다** — 확정 운영점 수치는 6절 표를 볼 것.

|---|---|---|

지금 NMS 는 겹친 박스 중 점수 최고 하나만 남긴다. wbf 는 그 덩어리의 좌표를
점수로 가중 평균한다. 덩어리의 절반 이상이 박스 4개 이상이라 평균낼 거리가
충분했다. **박스 합집합(union)은 전부 나빠졌다** — 오탐끼리 뭉쳐 커진다.

**AP75 만 내려간다**(종괴 0.022 → 0.016). 평균이 박스를 덩어리 중심으로
끌어당겨 느슨한 겹침에서는 더 맞고 빡빡한 겹침에서는 흐려지기 때문이다.
우리는 박스에 20px 를 붙여 잘라 1008 로 늘려 쓰므로 AP50 수준의 정확도가
필요하지 AP75 는 필요 없다. **AP50 이 우리 목적에 맞는 지표다.**

**끝단에서 확인됐다.** wbf@0.3 검출로 `eval_end2end.py` 를 다시 돌린 결과다.

| 서술어 몫 | nms@0.3 | **wbf@0.3** | 정답 박스 |
|---|---|---|---|
| 미세석회 | 91.6% | **96.8%** | 98.1% |
| 종괴 | 73.5% | **75.9%** | 82.7% |

**검출기 몫은 거의 안 변했다**(63.2% → 63.6%). 병변을 더 찾은 게 아니라
**찾은 병변의 박스가 정확해져서** 서술어가 제대로 된 조각을 받은 것이다.
박스 때문에 잃던 몫이 4.4%p → **1.9%p** 로 절반 이하가 됐다.

이것이 이 실험의 결론이다 — 재학습 없이, 저장된 검출을 다시 합치는 것만으로
끝단 민감도가 52.5% → **55.3%** 로 올랐다.

여기에 조직 마스크 필터(6-3절 ③)를 더해 최종 **61.7%** 가 됐다. 그 설정에서
미세석회 서술어 몫은 **97.5%** 로 정답 박스(98.1%)와 0.6%p 차이다.

**운영점을 wbf@0.3 + 조직 필터로 확정한다.**

**타일 간 점수 보정 — 시험했고 실패했다.** 쉬운 타일의 자신 있는 오탐이
어려운 타일의 정탐 위에 올라가는 문제다. 7가지 방식을 양방향으로 전부
시험했고 전부 현행보다 나빴다. 덩어리 크기가 합의가 아니라 **모호함**을 재기
때문이다. 근거는 6-4절에 있다.

**겹침 합치기 방식 — 끝났다.** 박스 합집합(union)은 전부 나빠졌고
점수 가중 평균(wbf@0.3)이 이겼다. 위 표가 그 결과다.

**에폭 수 — 하지 않기로 했다.** 6에폭은 기준선과 계산량을 맞추려고 정한
값이다. 검증 손실이 오르길래 과적합을 의심했으나 검출은 계속 좋아지고
있었으므로, 12에폭이 값싼 다음 실험인 것은 맞다. 다만 남은 기간과 재측정
비용(FROC · mAP · 끝단을 전부 다시 재야 한다)을 감안해 **에폭 6 을 최종본으로
확정했다.**

> **정정 (2026-09-06).** 그 뒤 에폭 8 까지 학습했고 그것이 최종본이다.
> 에폭 12 도 돌려 봤으나 과적합으로 기각했다(검증 손실 7.15→9.33).

**서술어에 '소견 없음' 클래스 — 가장 큰 남은 구멍이지만 이번에는 안 한다.**
지금 서술어 모델은 정상 조직을 본 적이 없어 어떤 조각을 넣어도 이상 소견을
만들어낸다. 그래서 검출 오탐이 그대로 조직검사 권고로 이어진다(6-3절 ①).
**필요한 데이터는 이미 있다** — 타일 작업에서 나온 정상 조직 타일 3,897장.
검출기는 그대로 두고 서술어만 다시 학습하면 되지만, 그 재학습이 일정 밖이다.
**고치지 않고 한계로 밝히고 간다.**

**VinDr 외부 검증 — 완료했다.** 443장으로 쟀다. 결과와 해석은 7-1절에 있다.

## 11. 서빙 실측 — 추론 시간 (2026-09-07)

평가 코드가 아니라 **서빙 경로 그대로** 쟀다. 소켓 타임아웃을 짐작으로 정하면
멀쩡한 판독이 끊기거나 죽은 요청이 앞을 막는다. CBIS 40장 · `PREDICT()` 직접 호출.

| | 카드 단독에 가까울 때 | 카드를 나눠 쓸 때 |
|---|---|---|
| 사진 1장 (95퍼) | 12.2초 | **26.9초** |
| 검사 1건 = 사진 4장 | 49초 | **108초** |
| 모델 적재 (기동 시 1회) | 20.2초 | |
| GPU 최고 점유 | **10.6GB** | |

같은 40장을 두 번 쟀는데 그 사이 GPU 를 함께 쓰는 다른 작업이 13GB → 21GB 로
늘었고 **값이 두 배가 됐다.** "한가할 때 잰 값으로 타임아웃을 정하면 바쁠 때
전부 끊긴다"를 우연히 실측한 셈이다.

**느려지는 원인이 둘이고 성질이 다르다.**

- **병변 수** — 바탕 7.7초 + 병변당 0.88초 (서술어를 병변마다 돌리기 때문). 상한 있음 — 실측 최대 21개에서 28.5초. **병변이 많아 느린 사진은 재시도로 못 넘긴다** — 타임아웃을 짧게 잡으면 정확히 놓치면 안 되는 사진만 골라서 죽는다.
- **GPU 경합** — 최댓값이 튄다. 상한 없음 — 다른 작업이 늘면 그대로 늘어난다.

**워커는 1개다.** 추론 중 최고 10.6GB 를 쓰고, 최고점에서 할당자 캐시가 121MB
뿐이라 줄일 수 없는 값이다. 32GB 카드를 다른 팀과 나눠 쓰는 조건에서는 두 번째
워커가 안 올라간다. 요청이 겹치면 줄을 서고, 검사 3건이 동시에 오면 세 번째는
시작도 못 한 채 약 430초를 기다린다 — 게이트웨이 기본 타임아웃에 먼저 잘린다.

### 그래서 정한 것

판독 요청은 **작업 번호를 즉시 돌려주고 결과는 나중에 받는다.** 타임아웃은
세 겹 — 사진 1장 54초 · 작업 1건 216초 · 클라이언트는 두지 않는다.

DB 스키마 v9 의 `ai_result.run_status` 가 이미 `queued`·`running`·`done`·`failed`
다. **큐 깊이에 상한을 두고 넘치면 거절해야 한다** — 무한정 쌓이면 뒤에 온 요청이
216초를 넘겨 전부 실패한다. (팀 결정 대기 — 10절)

## 12. 팀 접점

**우리 쪽에서 맞춘 것**

- BI-RADS 문자열화 — 4a·4b·4c 를 등급으로 유지. `cat_rank` 로 순서를 매겨 문자열 정렬에 안 기댄다
- 기권 응답 — `abstain_result()`. 적재 실패를 503 이 아니라 200+판정 불가로. 소켓 4b 와 같은 모양
- 없는 서버(`:8011`) 제거 — 문서와 코드에서

**다른 파트에 넘긴 요청**

- FastAPI — `report(socket_id, result, evidence=[])`
- 소켓 4b — `infer_mammo.abstain_result()` 를 그대로 쓸 것
- Django — 종합 리포트 호출은 `socket: "7"`
- `thresholds.yaml` — `mammo: {}` 가 `infer_mammo.DEFAULTS` 를 따른다는 주석만

**아직 안 정해진 것**

- 병변 0건 검사의 판독문 — llm-proxy 가 근거 없는 요청을 400 으로 거절한다. 정상 검사도 판독문은 나와야 하는데 지금 구조로는 못 쓴다 — **팀 결정 필요**
- 판독문 근거 문안 — 병변 하나를 생성 모델에 보여줄 한 줄로 바꾸는 규칙. `docs/evidence_text.md` 에 초안 — 미세석회 크기를 쓰지 말 것 · 종류를 단정하지 말 것 · BI-RADS 를 판정처럼 쓰지 말 것
- DB `ai_result.requested_at` — 지금은 끝난 시각과 추론 시간만 있어 "큐에서 기다린 시간"과 "추론이 느린 것"이 구분 안 된다. 둘은 고치는 방법이 정반대다
- DB `lesion.certainty` — 합이 아니라 평균으로. 축 개수가 종류마다 달라(석회 2·종괴 3) 종류를 섞어 정렬하면 미세석회가 구조적으로 덜 확실해 보인다
- 발표 시연 GPU 단독 사용 — 합의인지 예상인지 확인할 것. 예상이면 당일에 뒤집힌다
- 썸네일 생성 — Go 가 압축 DICOM 을 못 읽어 막힌 항목인데 우리 쪽은 이미 읽고 있다. 가져올 수 있다

Go 서비스 3종은 이미 완성돼 있다(5,789줄 + 시험). 남은 항목은 전부 외부 의존
(Orthanc 인스턴스 · 인증서 · Redis 결정 · C 라이브러리)이지 코드 문제가 아니다.

### 표시 형태 — 크기를 못 믿는 곳에서는 크기를 주장하지 않는다

| 종류 | 화면 표시 | 크기(mm) | 근거 |
|---|---|---|---|
| 미세석회 | 표식(marker) | 내보내지 않음 | 상자가 정답의 절반 크기. 이 해상도에서 범위를 신뢰할 수 없다 |
| 종괴 | 상자 | 낸다 | 상자가 정답 범위와 맞는다 |

응답에 `display` 항목이 붙고 `claims_extent` 가 그 그림이 범위를 주장하는지
아닌지를 명시한다. 미세석회는 `size_px`·`size_mm` 을 null 로 두고
`size_omitted_reason` 에 사유를 적는다 — 빈 칸으로 두면 받는 쪽이 다른 데서
숫자를 끌어온다.

`lesions[].box` 는 일부러 안 건드렸다 — 서술어 모델이 이 상자에서 조각을 오려
BI-RADS 를 낸다. 상자를 바꾸면 등급이 같이 바뀐다. 표시용 좌표는 `display.box`
로 따로 낸다.
