# 발표용 수치 정리 — MRI(소켓3)

이 문서의 숫자만 인용할 것. 근거는 대화 로그·워크스테이션 산출물(`postprocess_3d/verify_out/`), 서빙은 `mri/serving/README.md`.

최종 갱신 2026-09-02

---

## ⚠ 먼저 읽을 세 가지 — 수치를 말할 때 반드시 함께 붙일 것

### ① 외부 검증(test)이 없다 — 전부 같은 분포 안의 val이다

초음파(BUS-BRA valid → BrEaST test)와 달리, **MRI는 별도의 외부 데이터셋으로 검증한 적이 없다.** 모든 수치는 MAMA-MIA·Duke·AMBL 학습에 쓴 것과 **같은 분포의 val split(150장 균형표본)**에서 나왔다.

> 실제 운영(다른 병원·다른 장비)에서는 이 수치보다 낮게 나올 가능성이 높다. 외부 검증 없이 이 수치를 "실전 성능"으로 소개하면 안 된다.

### ② 조직검사 대상이 아니라 "임상시험/코호트 등록" 인구다

MAMA-MIA(NACT/ISPY 임상시험), Duke, AMBL 모두 **이미 종양이 있다고 확인된 환자**의 코호트다. 무증상 검진 인구와는 병변 유병률 자체가 다르다.

> 권장 표현 — *"이미 병변이 확인된 코호트에서, 위치·크기·밀도 추출을 보조했을 때의 성능"*

### ③ threshold를 바꾸면 성능 숫자가 크게 달라진다 — 어느 threshold인지 항상 명시

같은 모델, 같은 150장인데 threshold 하나로 tumor Dice가 0.72→0.44까지, malignant F1이 0.34→0.60까지 움직인다(1·4절). **수치를 말할 때 threshold를 반드시 같이 밝힐 것.**

## 1 · 핵심 수치 (서빙 확정 threshold 기준)

| 클래스 | 지표 | 값 | 서빙 threshold |
|---|---|---|---|
| **breast** | Dice | **0.9663** (th=0.5) / 0.9480 (th=0.8) | **0.8** |
| **tumor** | Dice | **0.7172** | 0.5 |
| dense tissue | Dice | 0.4808 | 0.5 |
| breast | 오탐율(정답 없는 이미지에서 예측) | 51.0%(th=0.5) → **35.0%(th=0.8)** | 0.8 |
| tumor | 오탐율 | **40.4%** | 0.5 |
| dense tissue | 오탐율 | 54.1% | 0.5 |
| malignant lesion (스코프 제외) | F1 (P=0.215,R=0.773, th=0.5) | 0.3366 | — |
| malignant lesion (스코프 제외, 참고용) | F1 (P=0.619,R=0.591, **th=0.8**) | **0.6047** | — |
| benign lesion (스코프 제외) | F1 (모든 threshold 시도) | 0.025~0.04 | — |

**한 줄 요약** — 유방 밀도(breast)는 사실상 완성 수준, 종양 위치(tumor)는 진짜 병변은 정확히 찾되 오탐이 절반 가까이 섞이는 수준, 양성/악성 구분은 서빙 스코프에서 제외했다.

## 2 · tumor 오탐율이 여전히 높은 이유 — 모델 오탐이지 3D 후처리 문제가 아니다

**환자 1명 스모크테스트(threshold=0.7 기준)에서:**
```
오탐 필터 전: 15개 후보
크기·연속성 필터 후: 5개
시트형(납작한 모양) 필터 후: 1개 (정답과 정확히 일치, 좌표오차 1mm 이내)
```
필터는 제 역할을 하지만, **환자마다 편차가 크다.**

**배치 검증(10명, 3차 모델) 결과:**
```
평균 GT(정답) 개수: 1.10개
평균 예측 개수(필터 적용 후): 2.10개
GT와 정확히 일치한 환자: 10명 중 4명
```

**원인 두 갈래로 확인됨:**
1. **순수 오탐** — 병변이 없는 자리에 모델이 헛짚음(대부분의 초과 검출)
2. **형태 왜곡** — 진짜 병변인데 모델이 납작하게(비정상 형태로) 예측해서, 오탐 필터가 이걸 노이즈로 오판해 지운 사례(`DUKE_399`) 1건 확인. 정답 부피 2.1cm³·최대직경 26.2mm의 정상적인 병변이었으나 예측 형태 자체가 왜곡됨.

→ **오탐율은 필터로 어느 정도 완화 가능하지만, 근본 해결은 모델의 검출·형태 정확도 개선이 필요하다.**

## 3 · "3차보다 5차가 나빴다"는 것이 확인됐다 — 실패 실험도 정직하게 기록

**5차(mamamia 하위셋 균형 샘플링 + loss dice 가중치 3배 상향)를 시도했으나, 목표했던 개선이 없었고 부작용이 확인됐다.**

| 지표 | 3차 | 5차 | 판정 |
|---|---|---|---|
| tumor 오탐율 | 40.4% | 40.4% | **개선 없음**(소수점까지 동일) |
| tumor Dice | 0.7172 | 0.7060 | 소폭 하락 |
| dense tissue Dice | 0.4808 | 0.5086 | 소폭 상승 |
| **malignant lesion F1** | **0.3366** | **0.2560** | **뚜렷한 악화** |
| benign lesion F1 | 0.0292 | 0.0387 | 소폭 상승(TP 2→3, 통계적으로 유의하다고 보기엔 표본이 너무 작음) |

**시간 부족으로 두 변경(샘플링+loss가중치)을 동시에 적용해 원인 분리가 안 됐다** — 어느 변경이 malignant를 악화시켰는지 특정할 수 없다. 다음 실험은 반드시 한 번에 하나씩 바꿀 것.

→ **3차를 최종 서빙 모델로 유지.**

## 4 · threshold 스윕 — 클래스마다 정반대 결론이 나왔다

같은 방법(threshold 조정)을 4개 클래스에 적용했는데, **클래스 성격에 따라 정반대 결과가 나왔다.**

| 클래스 | threshold 0.5→0.8 | 판정 |
|---|---|---|
| tumor | Dice 0.72→0.44(급락), 오탐율 40%→12%(개선) | **트레이드오프 — 손해가 더 커서 기본값 유지** |
| dense tissue | Dice 0.48→0.17(급락), 오탐율 54%→20%(개선) | **트레이드오프 — 기본값 유지** |
| **breast** | Dice 0.966→0.948(거의 그대로), 오탐율 51%→35%(개선) | **순이득 — threshold 0.8로 상향** |
| **malignant lesion**(스코프 제외) | F1 0.34→0.60(0.8에서 정점), 0.9에서 붕괴(F1 0.17) | **비선형 — 정점이 뚜렷이 존재함을 확인** |

→ **"threshold를 올리면 오탐이 준다"는 한 문장으로 일반화하면 안 된다.** breast만 무료로 이득을 봤고, tumor·dense tissue는 손해가 더 크다.

---

## 5 · 통계적 유의성 검정은 수행하지 않았다

**초음파 문서(§5)처럼 대응비교·부트스트랩 신뢰구간을 계산하지 않았다.** 위 threshold 비교·3차 vs 5차 비교는 모두 **동일 150장 표본에서의 단일 관측치 비교**이며, 표본 변동 폭에 대한 통계적 검정을 거치지 않았다.

> "malignant F1이 3차보다 5차에서 유의하게 낮다"처럼 통계 용어로 말하면 안 된다. **"이번 150장 표본에서는 낮게 나왔다"**로 표현할 것.

## 6 · 시도했으나 목표를 달성하지 못한 것

| 시도 | 결과 | 원인 |
|---|---|---|
| **negative sampling 대칭(2차)** | malignant F1 0.11→0.33(개선), benign F1 악화 | benign(256장) 대비 malignant(731장)이 3배 많아, 대칭 negative 관계가 benign에 불리하게 작용 |
| **negative sampling 비대칭(3차)** | malignant 유지, benign 그대로(F1 0.03대) | 데이터 절대량 자체는 어느 샘플링으로도 안 바뀜 |
| **AMBL 내부 균형샘플링(4차)** | benign TP 2→4(소폭 개선), tumor·malignant 등 나머지 지표 악화 | 순수 이득이 아니라 트레이드오프로 판단해 폐기 |
| **mamamia 하위셋 균형+dice가중치(5차)** | tumor 오탐 개선 없음, malignant 악화 | 원인 분리 안 된 상태로 동시 실험, 명확한 인과관계 확인 못함 |
| **3D 시트형 오탐 필터** | 대부분 환자에서 오탐 감소, 일부(DUKE_399)에서 진짜 병변까지 제거 | 필터 기준값이 환자 1명 실측으로 튜닝돼 일반화 부족 |

## 7 · 설계 판단과 근거 — 한 장 요약

| 판단 | 근거 |
|---|---|
| **2D 슬라이스 학습(3D 볼륨 통째 아님)** | 팀 공용 SAM3 텍스트쿼리 구조와 통일. 3D는 후처리(지표·시각화)로 역할 분리 |
| **benign/malignant lesion 서빙 제외** | F1 0.03~0.35 수준. AMBL 데이터 절대량(46명, benign 256장) 부족이 근본 원인이며 4차례 시도로도 해결 못함 |
| **위치는 학습된 breast 모델 대신 명암 기반 몸통 실루엣 사용** | breast 모델이 MAMA-MIA 소스에서 불안정(22조각으로 쪼개짐 확인). 명암 임계값 방식은 모델 성능과 무관하게 항상 동일 작동 |
| **클래스별로 다른 서빙 threshold** | 일괄 적용 시 tumor·dense tissue가 손해(Dice 급락). breast만 순이득 확인돼 개별 적용 |
| **3D 오탐 필터(복셀수+연속성+시트형)** | 슬라이스 단위 추론이라 슬라이스 간 일관성 없는 오탐이 3D에서 파편으로 나타남 - 다만 진짜 병변도 걸릴 수 있어 절대적 신뢰는 금지 |
| **negative sampling 클래스 쌍 비대칭 설계(3차)** | 대칭 설계 시 데이터 많은 클래스(malignant)가 적은 클래스(benign) 학습을 방해하는 게 실측으로 확인됨 |
| **크기는 mm/cm³ 단위** | 전처리 시 1×1×1mm 리샘플링 완료. 초음파(px 단위, 환산 불가)와 달리 이미 물리 단위 |

## 8 · 인용하면 안 되는 것

- ❌ "외부 병원 데이터에서도 이 성능이 나온다" — 외부 검증 전혀 안 함(①)
- ❌ "검진 정확도" — 전부 이미 병변 확인된 코호트(②)
- ❌ threshold 명시 없이 Dice·F1 숫자만 — 클래스·threshold 조합마다 크게 다름(③, 4절)
- ❌ "3D 위치(사분면·유두거리)가 완전히 검증됐다" — 축 방향(전후·상하·좌우)만 3명 표본으로 검증. 절대 좌표 정밀도, 다른 하위셋 일반화는 미검증
- ❌ "malignant lesion F1 0.60"을 서빙 가능 근거로 — 단일 150장 표본, 재학습·threshold 조정 후 스코프 재검토가 필요한 참고 수치일 뿐 확정 아님
- ❌ "5차 학습으로 개선했다" — 3차보다 나빠서 폐기함(3절)
- ❌ "오탐 필터가 오탐 문제를 해결했다" — 완화는 하나 진짜 병변을 지우는 사례도 확인됨(2절)
- ❌ 배치 검증(10명)을 "충분히 검증됨"의 근거로 — 표본이 작고 하위셋(ISPY1/2, NACT, DUKE) 편차가 아직 정량적으로 안 나뉨
