# 발표용 수치 정리 — 초음파(경로 B)

이 문서의 숫자만 인용할 것. 근거와 검정은 `experiments.md`, 서빙은 `serving_handover.md`.

최종 갱신 2026-08-28

---

## ⚠ 먼저 읽을 세 가지 — 수치를 말할 때 반드시 함께 붙일 것

### ① "검진 성능"이 아니다 — **조직검사 대상 병변에 대한 성능**

두 데이터셋 모두 **조직검사가 필요하다고 이미 판단된 병변**을 모은 집합이다.

| | 악성 비율 |
|---|---|
| BUS-BRA (train / valid) | **32.4% / 32.1%** |
| BrEaST (test) | **49.7%** |
| **실제 검진 인구** | **약 0.6%** |

**50~80배 차이다.** 무증상 검진 인구에 그대로 적용하면 위양성이 폭증한다.
발표에서 "검진 정확도"로 소개하면 잘못된 인상을 준다.

> 권장 표현 — *"조직검사가 권고된 병변 집합에서, 등급 판정을 보조했을 때의 성능"*

### ② valid 와 test 는 성격이 다르다

| | valid (BUS-BRA 374장) | test (BrEaST 197장) |
|---|---|---|
| 용도 | **개발용** — 헤드 선택·임계값 조정에 사용 | **외부 검증** — 1회만 사용, 결과로 조정 안 함 |
| 편향 | **낙관 편향 있음** | 없음 |
| 운영 기대치 | 참고만 | **이쪽에 가깝게 잡을 것** |

### ③ 표본 수는 이미지 수가 아니다

valid 374장은 **서로 다른 병변 212개**에서 나왔다(파일명 `-l`/`-r` 은 좌·우가 아니라
같은 병변의 다른 뷰). 유효 표본은 Dice 기준 약 301, 등급 기준 약 266이다.

## 1 · 핵심 수치

| | valid (개발용) | **test (외부 검증)** |
|---|---|---|
| **분할 Dice** | 0.9102 | **0.7882** |
| 분할 IoU | 0.8432 | 0.6873 |
| Dice p10 | 0.8351 | 0.5010 |
| Dice 중앙값 | — | 0.8598 |
| 빈 예측 | 0장 | 4장 (2.0%) |
| **등급 정확도** | 0.5321 | **0.4619** |
| **±1 이내 일치** | 0.9412 | **0.9492** |
| **BI-RADS 5 재현율** | 0.889 | **0.935** |
| 화면 표기 적중률 | 0.6979 | 0.8173 |
| '4~5' 구간 포함률 | 0.910 | **0.974** |

**한 줄 요약** — 분할은 외부 데이터에서 0.79, 등급은 정확히 맞히는 비율이 0.46 이지만
**인접 등급 안에 드는 비율이 0.95**, 악성 강력 의심(5)을 놓치지 않는 비율이 **0.935** 다.

---

## 2 · 분할이 −0.122 떨어진 이유 — **도메인 이동이지 장비 단서 의존이 아니다**

BUS-BRA 는 텍스트·캘리퍼 오버레이가 46.8%, BrEaST 는 2.3% 다.
"장비 표식을 외운 것 아니냐"는 검증이 이번 실험의 목적이었다.

**근거 세 가지 — 외운 것이 아니다.**

**① 등급별로 균일하게 떨어진다**
```
3: 0.803  ·  4a: 0.797  ·  4b: 0.774  ·  4c: 0.780  ·  5: 0.799
```
오버레이를 단서로 삼았다면 유무에 따라 갈렸을 텐데 전체가 고르게 내려갔다.

**② 하락이 평균이 아니라 꼬리에서 온다**
```
Dice ≥ 0.80    73%      중앙값 0.8598
Dice < 0.50    10.2%    ← 이 꼬리가 평균을 끌어내림
```
병변을 못 찾는 것이 아니라 일부에서 크게 실패한다.

**③ 실패 형태가 "검출 분산"이다**
```
다중 검출 비율   valid 6.1%  →  test 22.3%   (3.7배)
검출 1개 153장 Dice 0.8315  /  검출 2개+ 44장 Dice 0.63~0.67
```
병변을 하나로 확정하지 못하고 후보가 흩어진다 — 처음 보는 영상 특성에 대한
**불확실성**의 전형이며, 단서가 사라져 못 찾는 것과는 형태가 다르다.

## 3 · 화면 표기 적중률이 오른 것은 **성능 향상이 아니다**

0.6979 → 0.8173 로 올랐지만 **직접 비교하면 안 된다.**

```
BI-RADS 4·5 비율      valid 181/374 (48.4%)   →   test 185/197 (93.9%)
'4~5' 구간 적용 비율   valid 41.4%             →   test 58.9%
```

BrEaST 는 4·5 에 몰려 있어 **구간 표기에 구조적으로 유리한 인구 구성**이다.
모델이 나아진 것이 아니다.

**실제로 검증된 것은 두 가지다.**
- **구간 표기 포함률 0.974** — "4~5" 로 표기한 116장 중 97.4% 가 실제로 4 또는 5
- **확신도 3단계의 단조성** — 높음 0.972 · 보통 0.833 · 낮음 0.662

이 둘은 외부 데이터에서도 유지됐다. 표시 전략이 옳았다는 근거다.

---

## 4 · 알려진 약점 — 발표에서 먼저 말할 것

**① BI-RADS 4 재현율 0.309 — 139장 중 70장을 5로 올린다**

과잉 상향이다. 원인은 모델이 아니라 **라벨 체계**다 — BUS-BRA 에 4a/4b/4c 세분이 없어
4 가 악성률 60% 인 거대한 이질적 버킷이 됐고, **4 vs 5 분리 가능성 상한 자체가 AUC 0.758** 이다.
그래서 4↔5 를 확정적으로 가르는 대신 **"4~5" 구간으로 표기**하는 설계를 택했다.

**② BI-RADS 3 은 사실상 평가되지 않았다** — test 에 12장뿐. P(y>3) 특이도 0.417 의
신뢰구간이 매우 넓어 **이 수치로 판단하면 안 된다.**

**③ BI-RADS 2 는 전혀 평가되지 않았다** — test 에 0장. P(y>2) 경계는 측정 불가.

**④ 빈 예측 4장(2.0%)** — valid 에서는 0 이었다.

## 5 · 통계적으로 무엇이 확인됐고 무엇이 아닌가

같은 데이터를 두 모델이 평가하므로 **대응 비교 + 케이스 단위 군집 부트스트랩**으로 검정했다.
**seed 편차는 학습 재현성이지 표본오차가 아니므로 유의성 근거로 쓰지 않았다.**

### 확인된 것 (유의)

| 비교 | 차이 | 95% CI | 의미 |
|---|---|---|---|
| 분할 전용 − 조인트 | **+0.0107** | [+0.0039, +0.0182] | 등급 헤드를 붙이면 분할이 깎인다 |
| 분할 전용 − UNet결합 | **+0.0096** | [+0.0044, +0.0155] | 〃 |
| UNet 결합의 등급 악화 | **−0.0481** | [−0.0945, −0.0026] | 분할을 키우려는 변경이 등급을 해쳤다 |

→ **"한 방향의 간섭"이 실측으로 확인됐다.** 헤드를 분리한 이유다.

### 확인되지 않은 것 (유의하지 않음)

| 비교 | 차이 | 95% CI |
|---|---|---|
| 증강 − 무증강 (분할) | −0.0013 | [−0.0120, +0.0094] |
| UNet 결합 − 무증강 (분할) | +0.0011 | [−0.0065, +0.0087] |
| 조인트 − 5ep 분할만 | +0.0041 | [−0.0024, +0.0105] |
| **pos_weight p=0.25 vs 1.00 (등급)** | +0.0267 | [−0.0106, +0.0661] |

→ **조인트 구성끼리는 분할이 서로 구분되지 않는다.**
`pos_weight` 감쇠는 채택했으나 **"개선을 입증했다"고 말하면 안 된다** —
방향이 일관되고 비용이 없어 택한 것이다.

## 6 · 시도했으나 안 된 것 (발표에 쓸 것)

| 시도 | 결과 | 원인 |
|---|---|---|
| **데이터 증강** | 등급 acc −0.037 · 3→2 이탈 39→50장 | 기하 변환이 형태·경계 단서를 흐림. 분할은 무변화, 등급만 악화 |
| **악성 확률을 등급 보조 입력으로** | −0.0003 (노이즈 안) | 악성은 2·3 vs 4·5 는 잘 가르나(0%↔100%) **4 vs 5 는 AUC 0.609 로 무정보** |
| **UNet 픽셀 디코더 조인트** | 분할 동률, 등급 −0.0481 (유의) | 디코더 용량이 병목이 아니었다 |
| **최대 연결성분만 남기기** | Dice −0.0046 | 병변이 갈라져 보일 때 **큰 쪽이 오답이면 Dice 0** (3장 중 2장) |
| **4↔5 개선 추가 투자** | 중단 | 분리 가능성 상한 AUC 0.758 — **라벨 체계의 한계**이지 모델 문제가 아님 |

## 7 · 설계 판단과 근거 — 한 장 요약

| 판단 | 근거 |
|---|---|
| **등급을 직접 예측(CORAL)** | BUS-BRA 에 서술어 라벨이 없다. 순서형이라 2↔5 오류와 2↔3 오류를 구분해야 한다 |
| **헤드 분리 학습** | 등급 손실이 분할을 유의하게 깎는다(+0.0107). 분할을 동결하고 헤드만 재학습 |
| **기권 대신 확신도 표시** | 기권률 50% 는 화면에서 곤란. AI 가 회피하는 것보다 "이렇게 봤고 확신은 이 정도"가 판독 보조로 맞다 |
| **"4~5" 구간 표기** | 4 vs 5 분리 상한 AUC 0.758. 구별할 수 없는 것을 확정 표기하지 않는다. 포함률 0.974 |
| **임계값을 고정하지 않음** | 과소평가 vs 과잉검사는 운영 정책. 5,832 조합 표를 산출물로 남기고 기본값만 제시 |
| **형태 지표는 수치만** | 서술어 라벨이 없어 "불규칙" 판정 기준을 정할 근거가 없다 |
| **크기는 px 단위** | pixel spacing 이 데이터에 없다. 운영에서 DICOM `PixelSpacing` 으로 환산 |
| **위치는 모델이 내지 않음** | 검사 정보(DICOM)에서 받는다. 파일명 `-l`/`-r` 은 좌우가 아니다 |

## 8 · 인용하면 안 되는 것

- ❌ "검진 정확도" — 조직검사 대상 집합이다(악성 32~50% vs 검진 0.6%)
- ❌ valid 수치를 운영 기대치로 — 낙관 편향이 있다. test 를 쓸 것
- ❌ "화면 적중률이 외부에서 더 높았다" — 인구 구성 차이다
- ❌ `pos_weight` 조정의 등급 개선 — 유의하지 않다
- ❌ 악성 확률의 절대값 — 유병률이 50~80배 달라 신뢰할 수 없다(순위 지표로만)
- ❌ BI-RADS 2·3 성능 — test 에 0장·12장뿐이라 평가되지 않았다
