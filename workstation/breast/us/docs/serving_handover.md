# 서빙 인수인계 — 이동됨

이 문서는 **`../serving/README.md`** 로 옮겼다.

코드와 같은 폴더에 두어야 갈라지지 않기 때문이다. 서빙 관련 내용은 그쪽을 볼 것.

- 필요한 파일 · 서버로 옮길 때 고칠 경로
- 실행 방법 (`load_model` / `predict`) · FastAPI 예시 · 로딩 순서
- 출력 JSON 스키마 · 화면 표기 규칙
- VRAM · 로딩 시간 · 추론 시간
- 임계값·확신도 경계 (운영 정책 영역)
- 성능 (valid + test 대조)과 해석
- 마스크 신뢰도 "낮음" 비율을 도메인 이동 감시로 쓰는 법
- 주의사항 · 배포 후 점검 (`healthcheck.py`)
