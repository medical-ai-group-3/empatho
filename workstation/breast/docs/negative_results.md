# 실패 실험 기록 (Negative Results)

효과가 없었거나 오히려 나빠진 시도를 모은다. 같은 것을 다시 시도하지 않기 위해서,
그리고 발표에서 "시도했으나 효과 없었다"로 쓰기 위해서 남긴다.

각 항목은 **무엇을 · 왜 기대했나 · 결과 · 원인 · 판정** 순으로 적는다.
수치는 전부 실측이며 출처 파일을 함께 적는다.

## 1 · 데이터 증강 (초음파, 2026-08-26)

**시도** — train split 에만 즉석 증강 적용. 좌우반전(p=0.5) · 아핀(±10°, 0.9~1.1배) · 광도.
상하 반전과 큰 회전은 넣지 않았다. 후방음영은 언제나 병변 아래에 생기므로
뒤집으면 초음파에 존재하지 않는 영상이 된다.

**기대** — 학습 데이터가 1,495장뿐이라 증강이 가장 유력한 개선 수단으로 봤다.

**결과** — 등급이 나빠졌다.

| | acc | dice | 3→2 이탈 | 빈 예측 |
|---|---|---|---|---|
| 무증강 | **0.5481** | 0.9017 | **39장** | **0장** |
| 증강 | 0.5107 | 0.9004 | 50장 | 3장 |
| 차이 | **−0.037** | −0.001 | +11장 | +3장 |

**원인** — 분할(dice)은 사실상 변화가 없는데 등급만 떨어졌다. 기하 변환이 병변의
형태·방향 단서를 흐리는데, BI-RADS 등급 판정이 바로 그 단서(모양, 경계, 방향성)에
의존하기 때문으로 보인다. 분할은 "어디"만 맞히면 되지만 등급은 "어떻게 생겼나"를 봐야 한다.

**판정** — 기각. 현재 코드는 `self.augment = False` 로 하드코딩돼 있다
(`us/code/train_us_lora.py` 약 280행). `configs/us_lora.yaml` 의 `augment.enabled` 는
**읽히지 않는 죽은 설정**이므로 다시 시도하려면 그 대입을 config 와 연결해야 한다.
`_sample_aug()` 구현 자체는 남아 있다.

**출처** — `us/logs/aug_20260826_191906.log`, `us/eval_out/valid_aug_best.csv`

## 2 · 악성 확률을 CORAL 보조 입력으로 (초음파, 2026-08-28)

**시도** — 악성 헤드의 `sigmoid(logit)` 을 detach 해서 CORAL 헤드 입력에 덧붙였다
(256차원 → 257차원). 등급 손실이 악성 헤드를 역으로 끌지 않도록 detach 했다.

**기대** — 4↔5 경계가 최대 오분류원(4→5 45장)이었고, 악성 라벨 484장이
5등급 120장보다 4배 많으며 악성 AUC 가 0.928 로 높아서 쓸 신호가 있다고 봤다.

**결과** — 차이 없음. `pos_weight` 지수 4종 전부에서 동일했다.

| pos_weight 지수 p | aux 없음 | aux 있음 | 차이 |
|---|---|---|---|
| 0.25 | 0.5537 | 0.5535 | **−0.0003** |
| 0.50 | 0.5526 | 0.5508 | −0.0018 |
| 1.00 | 0.5312 | 0.5312 | 0.0000 |

seed 10개 재학습 기준 같은 설정의 acc **범위가 0.011~0.021** 이므로,
위 차이는 전부 노이즈 안이다.

**원인** — 두 가지다.

1. **악성은 4와 5를 못 가른다.** 등급별 악성 비율이 2등급 0.0% · 3등급 1.2% ·
   4등급 57.2% · 5등급 100.0% (valid) 라, 악성 신호는 `2·3` vs `4·5` 분리에는
   탁월하지만 4·5 부분집합 안에서의 구분 AUC 는 **0.609** 로 거의 무정보다.
2. **이미 특징에 들어 있다.** 같은 256차원 임베딩에서 악성 헤드가 AUC 0.928 을
   내므로, 그 정보를 스칼라로 다시 넣어도 새로 더해지는 것이 없다.

**판정** — 기각. 채택하지 않는다.

**출처** — `us/ckpt/heads_grid.json`, `us/code/analyze_variance.py` 출력

## 3 · 연결 성분 "최대 성분만 남기기" 후처리 (초음파, 2026-08-28)

**시도** — 예측 마스크의 연결 성분이 2개 이상인 경우가 valid 374장 중 18장(4.8%).
정답 마스크는 전부 1개이므로 작은 조각을 오탐으로 보고 가장 큰 성분만 남겼다.

**결과** — 나빠졌다.

| | Dice | IoU |
|---|---|---|
| 전체 · 원본 | **0.9028** | **0.8343** |
| 전체 · 최대성분만 | 0.9006 | 0.8333 |
| 해당 18장 · 원본 | **0.7812** | **0.6628** |
| 해당 18장 · 최대성분만 | 0.7349 | 0.6416 |

**원인** — 18장 중 15장은 작은 조각이 전체 면적의 0.3% 미만이라 제거해도 Dice 가 ±0.0003 이다.
의미 있는 크기의 조각은 3장뿐인데 **그 중 2장에서 큰 성분이 오답이었고 Dice 가 0 이 됐다**
(0.5626 → 0.0000, 0.4893 → 0.0000). 병변이 갈라져 보일 때 큰 쪽이 맞다는 보장이 없다.

**판정** — 기각. 대신 **전체 면적의 1% 미만 조각만 표시에서 제외**한다(`SPECK_FRAC = 0.01`).
`n_components` 를 출력에 실어 판독의가 조각 수를 알 수 있게 한다.

**출처** — `us/docs/experiments.md` 10-5절 · `us/code/shape_metrics.py`

## 부록 · 실패는 아니지만 상한으로 확인된 것

### BI-RADS 4↔5 는 헤드로 풀 수 있는 문제가 아니다 (2026-08-28)

train 특징에 로지스틱 회귀를 얹어 valid AUC 로 각 경계의 **분리 가능성 상한**을 쟀다.

| 경계 | valid AUC |
|---|---|
| P(y>2) | 0.854 |
| P(y>3) | 0.905 |
| P(y>4) | 0.864 |
| **4 vs 5 만** | **0.758** |

4와 5만 떼어놓으면 0.758 이 상한이다. 원인은 **BUS-BRA 에 4a/4b/4c 세분 라벨이 없다**는 것.
BI-RADS 4 가 악성률 60.1%(train) 인 거대한 이질적 버킷(547장, 36.6%)이 되어,
4c 에 해당하는 케이스가 5 와 영상 소견상 구별되지 않는다. **라벨 체계에서 온 상한**이며
헤드 구조나 손실 조정으로 넘을 수 없다.

→ 4↔5 를 확정적으로 가르는 대신 **등급 + 확신도** 로 내보내는 방향으로 전환했다.
