## 4. 결론

### bilinear 적용 — 적용 권장, 단 근본 해결은 아님
- 같은 로짓에서 방식만 바꿨을 때 원본 해상도 간질 Dice 0.803 → 0.814, 종양 0.812 → 0.825 (pooled).
  크롭별로도 간질 106장 개선 / 54장 악화 (Wilcoxon p=6e-5), 종양 98 / 52 (p=0.002). 방향이 일관되고 비용이 없다.
- 이득은 >512px 큰 크롭에서 크다 (간질 중앙 0.746 → 0.765, 13장 중 10장 개선). ≤512px 작은 크롭은
  격자 한 칸이 수 px 라 두 방식 차이가 작다 (다른 픽셀 비율 평균 1.7%).
- 간질 면적 AI/GT 중앙값은 두 방식 모두 1.007 — sTIL 분모(간질 면적)를 체계적으로 바꾸지 않는다.
  즉 bilinear 는 경계 정확도만 올리고 sTIL 수치를 흔들지 않는 안전한 변경.
- **기존 0.904 는 16×16 격자 기준**이며 원본 해상도 실제 성능은 0.80~0.81. 격차의 대부분은 큰 크롭(픽셀 비중 79%)에서
  16×16 격자가 경계를 표현하지 못하는 해상도 한계로, bilinear 로 메워지는 몫은 약 0.01 뿐이다.
  근본 해결은 기존 결론대로 고해상도 헤드(conv/DPT) 재학습.

### 밀집 구역 recall — 떨어짐. 핵 병합은 일부 원인, 주원인은 밀집 군집의 검출 누락
- 1:1 recall: 하 0.675 / 중 0.756 / **상 0.506**. 반경 방식은 하 0.693 / 중 0.821 / 상 0.709 로 하락폭이 작다.
  상위 구간에서 1:1 과 반경의 차이(0.20)가 가장 크다 = 근처에 TIL 검출은 있는데 GT 수만큼 안 나온다.
- 상위 구간에서 검출 세포 총수가 GT 의 0.70배 (중 2.22배) — p_til 무관하게 세포 자체를 적게 찾는다.
  p_til<0.5 로 탈락한 비율은 2% 뿐이라 **분류가 아니라 검출/분할 단계 문제**.
- 병합 가설: GT 핵 ≥2개(8px 이내)를 덮는 검출은 1개를 덮는 검출보다 면적이 1.31배 크다 (p=2e-9) → 병합은 실재한다.
  그러나 그런 검출은 상위 구간 AI TIL 의 6.9% (87개) 로, 놓친 GT 1,031개 중 병합으로 설명되는 몫은 수십~100여 개 수준.
  나머지는 "반경 15px 안에 검출 자체가 없음"(57%) 과 "이웃이 가져감"(41%, 병합+인접 누락 혼재).
- 극단 사례 v100(GT 96점, 밀도 9,272/mm²)은 **세포 0개 검출** — 빽빽한 림프구 군집을 통째로 놓침.
  v100 을 빼도 상위 구간 1:1 recall 0.531 로 여전히 가장 낮다.
- 따라서 "밀집 구역 recall 저하" 는 확인, "핵 병합" 은 부분적으로만 지지. 개선 후보는 CellViT 후처리
  (watershed/거리맵 임계값, 최소 면적) 조정과 밀집 림프구 군집 대상 검출 재학습.

### 주의할 점
- socket2 학습 미사용 39장은 밀도 구간당 7~8장이라 구간별 수치는 참고용. 합계 recall 은 미사용 0.657 vs 전체 0.628 로
  학습셋 겹침이 recall 을 부풀린 흔적은 보이지 않는다.
- 하위 구간·N/A 구간 precision 이 낮다 (0.37 / 0.17). GT 점 0개인 98장에서 AI TIL 326개가 나와서다.
  TIGER 점 라벨이 크롭 안 모든 림프구를 빠짐없이 찍은 것인지 확인 전에는 FP 로 단정하지 말 것.
- 상위 구간 GT 최근접 간격 중앙값 11.4px < 매칭 반경 15px. 1:1 매칭이 인접 GT 끼리 경쟁하므로
  1:1 recall 은 보수적(낮게), 반경 recall 은 관대하게(높게) 나온다 — 두 값을 함께 볼 것.
- good 예시(v134)는 간질 Dice 1.0 동률 30장 중 하나 (100% 간질 크롭이라 Dice 는 자명). 대신 같은 크롭이
  밀집 림프구에서 AI TIL 20개 vs GT 91개로 과소검출을 잘 보여준다.
