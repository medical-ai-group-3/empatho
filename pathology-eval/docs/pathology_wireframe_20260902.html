영상의학과의 1차 판독 잠금(AI 대조 전 게이트)과 달리, 병리 화면에는 그런 잠금이 없다 — "병리 편향 통제는 만들지 않는다. 병리의 판단이 기준"(사양서 8-2). 의도된 비대칭이다.

참조 패널 뷰어 = Cornerstone3D (병리 WSI 뷰어와 별개)

이 패널은 영상의학과 판독 화면과 같은 Cornerstone3D + DICOMweb으로 맘모·초음파·MRI 영상을 렌더링한다. ⑧의 병리 WSI 뷰어(OpenSeadragon + DZI)와는 별개의 뷰어 라이브러리이며, 하나의 병리 화면 안에서 두 라이브러리가 공존한다 — WSI는 OpenSeadragon, 우측 영상 참조 패널은 Cornerstone3D. 데이터 소스도 좌표계도 서로 독립적이다.

기권 없음

ai_result.abstained 필드는 테이블 구조상 존재하나 병리 소켓에는 적용하지 않는다 — "병리의 판단이 기준"(사양서 3-7). 대신 오차범위(stil_interval_low/high)로 불확실성을 전달한다.

stil_percent 절대값 표기 주의

병리의사 스코어 82건 대조 결과 순위는 일치하나(ρ=0.798) 절대값은 임상 스케일 대비 약 1/12. 캘리브레이션 반영 여부를 백엔드팀과 확정 후 화면 값 결정 필요 — docs/stil_pipeline_limitations.md 참조.

tsr_percent 정의 확인 필요

DB 컬럼 설명엔 "§0-3에 근거"라 되어 있으나, 사양서 7장엔 여전히 "정의 미확정(Q6)"으로 남아있음 — 최일운님 확인 후 화면에 한 방향으로 확정 표시.

B분류는 반드시 사람이 고른다

"B분류는 병리의가 직접 고른다. AI는 양성/악성만 낸다"(사양서 3-7) — AI 제안값으로 자동 채우는 UI를 만들지 않는다.

허용값 확인 필요

"트리거는 사람의 요청이 아니라 finalized_at 이라는 상태 변화"(사양서 4-4). 확정 순간 discordance_flag가 규칙 5종(rule1~rule5)으로 자동 평가된다.

report 연결 확인 필요

영상의학과는 FINAL 시 report(report_type='imaging')를 별도 insert. 병리도 동일한지 문서상 불명확 — API팀 확인 필요.

정정 경로 없음

"확정 후 오류는 새 검체로 처리한다"(사양서 8-2). finalized_at이 찍힌 행은 다시 열리지 않는다.

뷰어 프로토콜 — 병리 WSI는 통일 대상이 아니다

병리 WSI 판독 화면은 OpenSeadragon + DZI(Deep Zoom Image)를 쓴다. 영상의학과(맘모·초음파·MRI)는 Cornerstone3D + DICOMweb으로 통일, 병리 WSI만 OpenSeadragon + DZI로 예외 — WSI 규모(장당 수 GB·기가픽셀 피라미드) 때문이다.

이 화면과 별개로, 병리 화면 우측 영상 참조 패널(④)은 Cornerstone3D로 영상을 렌더링한다 — 한 병리 화면 안에서 병리 WSI 뷰어(OpenSeadragon)와 영상 참조 뷰어(Cornerstone3D) 두 라이브러리가 공존한다.

build_status가 ready가 아니면 이 화면 자체가 409 PYRAMID_NOT_READY로 열리지 않는다 (③ 참조).

사양서 19-5 갱신 필요

19-5 표는 맘모·초음파를 OpenSeadragon/DZI로 적고 있으나 낡은 내용 — 공식 정정 대상 (서정은 확인 2026-09-02). 착수 전 확인 필요 사항 참조.

  • API 명세서 7.5 슬라이드 등록 엔드포인트 경로 — pathology-results 기준인지 specimens 기준인지 (③ 참조)
