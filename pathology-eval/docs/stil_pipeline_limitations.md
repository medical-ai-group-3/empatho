# sTIL 파이프라인 — 현재 한계와 개선 방향

작성 2026-08-31. 대상: `code/stil_inference_pipeline.py` (val 281장 기준).

## 1. 파이프라인 구성

| 단계 | 모델 | 확정 근거 |
|---|---|---|
| Socket1 조직분할 | Virchow2(동결) + Linear head, TAND 사양 (`linear_tand`) | 6개 후보 비교. 간질 Dice 0.904, 전체 pixel acc 0.883 |
| Socket1 → 간질 마스크 | 16×16 격자 예측 → **원본 해상도 nearest 업샘플** | 스케일 불일치 방지 |
| Socket2 세포검출 | CellViT-SAM-H (사전학습, 40x) + 원본해상도 512 타일링 | 큰 이미지 검출 recall 12% → 94% 복구 |
| Socket2 세포분류 | frozen CellViT 토큰 + weighted LinearClassifier 헤드 | 가중 CE(5:1) + drop 0.5. val AUROC 0.966 |
| sTIL 공식 (표준) | `Σ(간질 내 면역세포 세포면적) / (간질 면적) × 100` | 국제 TIL WG 정의 |

**현재 결과 (nc_ratio=1.5, 임계값 0.5, val 238/281 유효):**
median 3.2%, p75 12%, p90 18%, p95 21%, max 37%. 29%가 ≥10%.
→ 임상 sTIL 분포(대략 10~60%, 다수 케이스가 낮은 편)보다 **전반적으로 낮음**.

## 2. 한계 목록

### 2-1. 핵 면적 ≈ 세포 면적 근사 (`--nc_ratio`)

- **현상**: CellViT는 **세포핵**을 분할하지만, WG sTIL은 "간질 면적 중 단핵 면역세포가 **차지하는 면적**" 즉 세포(세포질 포함) 기준.
- **정량**: 이번 val에서 검출된 TIL 세포핵 등가지름 중앙값 **5.1 µm** (면적 20.4 µm²). 소림프구 세포지름은 표준 조직학 참고치로 ~7–8 µm(핵 ~6–7 µm, 세포질은 얇은 rim), 형질세포는 세포질이 풍부해 세포지름 10–20 µm.
- **보정계수 근거**: 세포면적/핵면적 = (세포지름/핵지름)². 소림프구 8 µm / 6.5 µm → **≈ 1.5** (기본값). TIGER TIL 정의가 "림프구 + 형질세포"이고 형질세포(면적비 ~4)가 섞이면 실효 계수는 상향(1.5~2.0). 활성화 림프구도 더 큼.
  - 참고: Ross & Pawlina, *Histology: A Text and Atlas*; Young et al., *Wheater's Functional Histology* (림프구/형질세포 크기).
- **영향**: 1.5 적용 시 sTIL median 2.2 → 3.2, max 24 → 37. 여전히 하한 방향.
- **개선**:
  - (경량) 계수를 형질세포 비율 반영해 상향, 또는 코호트별로 GT 매칭해 캘리브레이션.
  - (정식) 핵 마스크를 고정 반경으로 dilation 하거나, 세포질까지 분할하는 모델 사용. CellViT는 핵 전용이라 구조 변경 필요.

### 2-2. 밀집 림프구 구역에서 병합 검출

- **현상**: CellViT-SAM-H는 **40x (0.25 µm/px)** 학습 모델인데 TIGER crop은 **≈ 0.5 µm/px** (2× 배율 불일치). 핵이 모델 기대보다 절반 크기로 보여, HoVer 워터셰드(`object_size=10, k_size=21`)가 인접 핵을 하나로 병합.
- **정량**: sTIL이 높아야 할 밀집 구역에서 개수·면적이 동시에 과소. 예: `240S` — 간질 내 면역세포 987개 검출인데 sTIL 13% (밀집도 대비 낮음).
- **영향**: sTIL 상한이 눌림. 정상~중간 밀도 구역은 영향 적음(검출 recall 94~97%).
- **개선**:
  - (중간) 입력 crop을 2× 업스케일해 0.25 µm/px로 맞춰 검출 → **단, socket2 분류 토큰이 바뀌므로 재학습 필요**.
  - (경량) 워터셰드 커널을 0.5 µm/px에 맞게 조정 (`resolution=0.5` 옵션 존재, `object_size=3, k_size=11`) — 재추출만 필요, 재학습 불요. 효과 검증 필요.

### 2-3. Socket2 큰 이미지 분류 성능

- **현상**: weighted 헤드의 이미지 크기별 성능 차이.

| 구간 | AUROC | AP | recall@0.5 | precision@0.5 |
|---|---|---|---|---|
| 작은(≤512) | 0.957 | 0.924 | 0.94 | 0.77 |
| **큰(>512)** | 0.945 | **0.614** | **0.67** | **0.49** |

- **원인**: 큰 이미지의 밀집 림프구 셀은 학습 데이터가 원래 거의 없었음(구 파이프라인 512 CenterCrop). 타일링 재추출로 학습셋에 편입(TIL 3개 → 9,235개)했으나 여전히 어려운 도메인 + 해당 구간 TIL 유병률 6%.
- **영향**: 큰 이미지에서 면역세포의 1/3을 놓치고(recall 0.67), 검출된 것의 절반이 오탐(precision 0.49) → 분자가 양방향으로 흔들림. AUROC는 높아 임계값 튜닝 여지 있음.
- **개선**:
  - (경량) P(TIL) 임계값을 0.3~0.4로 낮춰 recall 확보 (precision 추가 하락 감수).
  - (정식) 큰 이미지 hard-negative 증강 재학습, 또는 큰 이미지 전용 파인튜닝. 2-2와 함께 하는 게 효율적.

### 2-4. 조직 모델 16×16 해상도 → 얇은 간질 누락

- **현상**: `linear_tand`는 224px 입력 → **16×16 격자(총 256칸)** 예측. 1200px 이미지에서 1칸 ≈ 75px. 얇은 간질 띠(< 75px)는 격자 단위로 통째 누락 가능.
- **정량**: val 281장 중 **43장(15%)이 `stroma_status=absent`** (간질 픽셀 0 → sTIL 산출 불가).
  - 이 중 실제로 종양/괴사/지방/가장자리로 간질이 없는 경우가 다수(34장, 면역세포도 거의 미검출).
  - 조직 모델이 실제 간질을 놓친 것으로 추정되는 경우 **~9장(3%)** (면역세포 다수 검출인데 간질 0).
- **영향**: 실질적 "평가 불가" 비율은 3% 수준. 나머지는 정당한 미평가.
- **개선**:
  - (정식) 조직 모델을 conv/DPT head 등 고해상도 출력으로 교체 → socket1 재학습.
  - (경량) 조직 예측을 16×16 대신 patch stride를 촘촘히 하거나, 여러 스케일 TTA.
  - **운영 규칙 (아래 3절)**: 간질 미검출 타일은 슬라이드 집계에서 제외하고, 슬라이드 전체가 미검출이면 "평가 불가"로 병리의 검토 회부.

### 2-5. 공간 게이팅이 centroid 기반

- **현상**: 면역세포가 간질 안인지 판정할 때 **centroid** 픽셀만 확인. 세포가 간질/종양 경계에 걸치면 면적을 clipping 없이 전부 분자에 포함(또는 전부 제외).
- **영향**: 경계부에서 소폭 오차. 전체 면역세포의 13%가 게이팅으로 제외됨(4881 → 4246) — 대체로 종양 둥지 내 세포를 올바로 제외.
- **개선**: contour를 간질 마스크로 clipping해 겹치는 면적만 카운트 (구현 비용 낮음, 정확도 소폭 개선).

### 2-6. 절대값 검증 (TIGER WSITILS 파일럿 완료 2026-08-31)

- **데이터**: TIGER WSITILS `s3://tiger-training/wsitils/` — 82 WSI + `tiger-til-scores-wsitils.csv`(공인 유방병리의 육안 TIL score 0~100). 파일럿으로 점수 스펙트럼 커버 **15장** 다운로드(~3.7 GiB).
- **WSI 파이프라인** (`code/wsi_stil_pipeline.py`): 타일 단위 로직 재사용, 512px 조직 타일 무작위 600개 서브샘플, 슬라이드 단위 면적 집계. ~1분/슬라이드.
- **결과** (`code/wsi_stil_validate.py`, `stil_results/wsi_stil_validation.png`):

| 지표 | 전체 15장 | 이상치 3장 제외* |
|---|---|---|
| Spearman ρ | **0.78** (p=0.0006) | **0.92** (p<0.0001) |
| Pearson r | 0.74 | 0.82 |
| 스케일 인자 k* (원점최소제곱) | 11.5 | 10.9 |
| 캘리브 후 MAE (0~100) | 17.7 | 15.5 |

\* 108S("many neutrophils"), 123S("necrosis+++++"), 224B — GT 육안 스코어가 림프구 외 요소에 크게 영향받는 케이스. 파이프라인(림프구·형질세포 특이)이 오히려 더 보수적일 수 있음.

- **해석**: **순위상관은 강함** (ρ 0.78~0.92). 파이프라인이 병리의 TIL 평가 순서를 잘 따라감. 단 절대 스케일이 **~11× 낮음** → 캘리브레이션 필요.
- **스케일 인자 k*≈11의 분해**: 생물학적 핵→세포 면적(~2×) + 밀집구역 병합검출(~3×, 한계 2-2) + 분류기 recall 0.67(~1.5×) + 육안 스코어의 상향 편향(~2×, 문헌상 병리의 육안 TIL은 형태계측 대비 높게 나옴). 즉 **단일 상수가 여러 원인을 흡수** — 캘리브는 임시방편, 근본 해결은 재학습(2-2, 2-3).
- **운영 권장**: `slide_stil_calibrated ≈ 11 × slide_stil_nucleus` (또는 아핀 `10·nuc + 7`). 저/중/고 TIL 3분류 용도로는 사용 가능, 연속값 정밀도는 캘리브 후 MAE ~16으로 제한적.
- **개선**: 전체 82장으로 확대 시 k* 안정화 + 코호트별 캘리브. 재학습으로 2-2/2-3 해결하면 k* 가 생물학적 ~2로 수렴할 것으로 기대.

### 2-7. 배율(mpp) 하드코딩

- **현상**: TIGER crop을 0.5 µm/px로 가정(`--mpp 0.5`). 파일명·데이터에 명시 메타데이터 없음. 검출 세포핵 크기(등가지름 중앙값 6.2 µm, 림프구 핵 5~7 µm 부합)로 역검증한 값.
- **영향**: sTIL **비율**은 분자·분모 모두 px² 라 mpp 무관. µm² 환산값과 sanity check만 영향.
- **개선**: 신규 데이터는 슬라이드 메타데이터에서 mpp 추출.

## 3. `stroma_status=absent` 처리 방침

**의견: sTIL을 0이 아니라 "평가 불가(None)"로 두는 것이 맞다.**

- WG 정의상 sTIL은 **간질 구획 안에서** 평가. 간질이 없으면 분모가 없어 **정의되지 않음**. 0%로 두면 "간질은 있는데 TIL이 없다"는 다른 의미가 되어 오해를 유발.
- 실제 운영(슬라이드 단위):
  1. 슬라이드를 타일로 나눠 각 타일의 (간질 내 면역세포 면적, 간질 면적)을 구함.
  2. **슬라이드 sTIL = Σ(간질 내 면역세포 면적) / Σ(간질 면적)** — 면적 가중 집계.
  3. 간질이 없는 타일은 분자·분모 어디에도 기여하지 않음(자동 제외). 별도 0 처리 불필요.
  4. 슬라이드 **전체**에 검출 가능한 간질이 없으면(전 타일 absent) → "sTIL 평가 불가(non-evaluable)"로 보고하고 병리의 검토 회부. WG도 종양-only/괴사 위주 절편은 non-evaluable로 분류.
- 이번 val의 15%(43/281)는 **단일 소형 ROI** 기준이라 부풀려진 수치. 슬라이드 스케일 + 개선된 조직 모델에서는 훨씬 낮아짐(추정 1~3%).

## 4. 개선 로드맵 요약

| 항목 | 방법 | 재학습 | 기대 효과 |
|---|---|---|---|
| 2-1 핵→세포 면적 | nc_ratio 캘리브레이션 / 핵 dilation | 불요 | sTIL ~1.3~2× 상향 |
| 2-2 밀집 병합검출 | 워터셰드 `resolution=0.5` 재추출 | 불요(재추출) | 밀집구역 개수·면적 개선 |
| 2-2/2-3 | 2× 업스케일 입력 + hard-neg 재학습 | **socket2 필요** | 큰 이미지 recall·분할 동시 개선 |
| 2-3 임계값 | P(TIL) 0.3~0.4 | 불요 | 큰 이미지 recall↑ |
| 2-4 조직 해상도 | conv/DPT head | **socket1 필요** | absent 비율↓, 간질 면적 정확도↑ |
| 2-5 게이팅 | contour clipping | 불요 | 경계부 정확도 소폭 |
| 2-6 검증 | TIGER WSIBULK 확보 | - | 절대 정확도 검증 가능 |

**즉시 가능(재학습 불요)**: 2-1, 2-2(재추출), 2-3(임계값), 2-5. 
**재학습 필요(일정 고려)**: 2-2(업스케일), 2-3(hard-neg), 2-4.

## 5. 발표용 한 줄 요약

> "검출 파이프라인의 스케일 버그(큰 이미지 5.3× 축소)와 sTIL 공식의 차원 불일치를 바로잡아, sTIL 값이 검출 품질에 좌우되지 않고 조직 크기와 무관하게 일관되게 나오도록 만들었다. 남은 gap(임상 대비 낮은 절대값)은 (1) 핵 면적을 세포 면적으로 근사, (2) 40x 모델에 20x 데이터를 넣어 밀집 구역에서 병합 검출, (3) 큰 이미지 분류 recall 0.67 때문이며, 앞의 둘은 재학습 없이, 마지막은 재학습으로 개선 가능하다."
